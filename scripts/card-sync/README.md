# 카드 정리 봇

노션 카드 DB 를 매일 아침 어제 상태와 비교해서 바뀐 카드만 정리한다. 사람은 카드 DB 에서 **추가 · 수정 · 삭제(상태 「삭제」)** 만 한다.
돌리는 곳은 GitHub Actions (`.github/workflows/card-sync.yml`, 매일 06:00 한국 시간). AI 를 쓰지 않는 규칙 스크립트라 매번 같은 결과가 나온다.
노션 쪽 안내 · 「출시됨」 스위치 · 마지막 실행 결과는 노션 「🃏 카드」 칸의 「🤖 카드 정리 봇」 페이지에 있다.

## 하는 일

| 본 변화 | 늘 | 출시 후 (「출시됨」 체크) 에만 |
| --- | --- | --- |
| 새 카드 | 빈 ID 채우기 (그 종류 마지막 번호 + 1, 삭제된 번호 포함), 빈 칸이 있으면 카드 페이지에 댓글 | 확정이면 패치 노트 「신규」 |
| 확정됨 | 다국어 `card.<ID>.name` · `.text` 줄 만들기 · 고치기, cards.json 에 없으면 「개발 확인 필요」 댓글 | 패치 노트 「신규」 |
| 확정 카드가 바뀜 | 이름 · 문구가 바뀌면 다국어 한국어를 고치고 「원본 바뀜」, 능력이 바뀌면 「개발 확인 필요」 댓글 | 패치 노트 「예정」 줄, 능력이 바뀌면 어제 페이지를 「카드 옛 버전」 에 보관 |
| 확정에서 빠짐 (삭제 · 제안 · 미정) | cards.json 에 있으면 「개발 확인 필요」 댓글, 삭제면 다국어 메모에 「[삭제된 카드]」 | 패치 노트 「삭제」 |

* **저장소:** cards.json 에 이미 있는 확정 카드의 이름 · 문구 · 장수 · 등급 · 종류가 노션과 다르면 `cards.json` 과 `11-card-list` 1-1 표 · 1-2 제목을 고쳐 `bot/card-sync` → `develop` PR 을 연다 (열려 있으면 다시 맞춰 덮는다). 새 카드는 효과를 만들어야 하므로 넣지 않는다. 머지한 뒤 Unity `Chapchu/카드 가져오기`.
* **변경 종류:** 카드 문구와 본문 규칙 절(`효과` · `추가 사용 조건` · `발동 조건` · `예외` 로 시작하는 제목 아래)을 비교한다. 숫자만 다르면 수치 변경 — 상향인지 하향인지 모르므로 종류를 비우고 「확인 필요」. 글이 다르면 규칙 절이 바뀐 경우 리워크, 카드 문구만 바뀐 경우 문구. 대상 · 종류가 바뀌면 리워크. 이름이 바뀌면 「확인 필요」 (다른 카드가 된 것일 수 있다).
* **패치 노트 합치기:** 같은 카드에 봇이 쓴 「예정」 줄이 있으면 새 줄 대신 그 줄의 「이후」 를 고친다. 종류는 더 큰 변경일 때만 바꾼다 (문구 < 수치 · 상향 · 하향 < 리워크 < 신규 < 삭제).
* **변경 기록:** 출시 전후 · 제안 · 확정을 가리지 않고, 카드 하나에 하루 동안 바뀐 칸(이름 · 상태 · 종류 · 대상 · 등급 · 장수 · 문구 · 본문 규칙)을 노션 「🧾 카드 변경 기록」(봇 페이지 안) 에 한 줄씩 남긴다 — 추가 · 수정 · 상태 · 삭제. 노션 휴지통으로 사라진 페이지도 「삭제」 로 남긴다.
* 아무것도 지우지 않는다. 패치 노트 「적용」 · PR 머지는 사람이 한다.

## 처음 한 번

1. 노션 → 설정 → 연결 → 「통합 개발 · 관리」 → 새 내부 통합. 기능: 콘텐츠 읽기 · 업데이트 · 삽입, 댓글 읽기 · 삽입.
2. 그 통합을 다섯 곳에 연결한다 (각 페이지 「…」 → 연결): 카드 DB · 📝 패치 노트 · 🗄️ 카드 옛 버전 · 🌐 다국어 문구 · 🤖 카드 정리 봇.
3. GitHub 저장소 → Settings → Secrets and variables → Actions → `NOTION_TOKEN` 에 통합 토큰.
4. GitHub 저장소 → Settings → Actions → General → 「Allow GitHub Actions to create and approve pull requests」 켜기.
5. 예약 실행은 이 워크플로가 `main` 에 들어간 뒤부터 돈다. 처음엔 Actions → 카드 정리 봇 → Run workflow (dry_run 체크) 로 할 일만 보고, 그다음 한 번 그냥 돌려 기준을 만든다.

## 한계

* 하루 한 번이라 반영이 하루 늦다. 급하면 Run workflow.
* 하루 안에 여러 번 고치면 하루 끝 결과만 남는다 (옛 버전도 어제 것).
* 노션에서 페이지를 휴지통에 넣으면 봇은 모른다 — 상태 「삭제」 를 쓴다.
* 옛 버전 복사: 그림 · 안에 든 DB 는 「원래 카드 페이지 참고」 한 줄로 바뀌고, 3단계 이상 들여쓴 블록은 2단계까지만 옮긴다.
* 어제 상태는 Actions 캐시에 있다. 7일 넘게 안 돌면 지워져서 다음 실행이 다시 기준만 만든다.

## 손으로 돌리기

```
NOTION_TOKEN=... python scripts/card-sync/card_sync.py --snapshot snap.json --repo . --dry-run
```
