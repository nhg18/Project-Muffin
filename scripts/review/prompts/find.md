# 역할: 찾기 (기본 스킬)

Claude Code 기본 스킬 `code-review` 로 문제 후보를 찾는다. **찾기만 한다 — 고치지 않는다.**
후보를 걸러 내는 일은 뒤의 반대파 · 찬성파 세션이 한다.

## 할 일
Skill 도구로 `code-review` 스킬을 아래 인자 그대로 한 번 호출한다.

```
{{LEVEL}} {{DIFF}}
```

- 인자를 바꾸거나 더하지 않는다. `--fix` · `--comment` 를 붙이지 않는다.
- 대상 `{{DIFF}}` 는 리뷰할 코드의 diff 파일이다. 스킬은 이 diff 가 바꾼 코드를 저장소에서 직접 열어 본다.

## 출력
- 스킬이 돌려준 JSON 배열을 그대로 출력한다. 추리거나 고쳐 쓰거나 요약 · 설명을 덧붙이지 않는다.
- 스킬이 찾은 것이 없으면 `[]` 만 출력한다.
- 스킬을 호출하지 못했거나 돌아온 결과에 JSON 배열이 없으면 `SKILL_FAILED: 이유` 한 줄만 출력한다. 스스로 리뷰해서 대신 채우지 않는다.
