**최종 수정일**: 2026-11-08

## 3. 카드 구성

| 항목 | 설명 |
| --- | --- |
| 카드 타입 | 행동 / 함정 / 카운터 |
| 사용 조건 | 카드를 사용·발동하기 위해 필요한 조건 |
| 대상 | 효과가 적용되는 플레이어 또는 카드 |
| 효과 | 처리 시 적용되는 결과 |
| 등급 | 일반 / 고급 / 희귀 / 개판 — 카드마다 하나 (확정 2026-11-08, PM). 앞면 연출이 등급마다 다르다 (`10-ui` 2-1 「카드 등급 연출」). 규칙 · 덱 장수와의 관계는 **미정** (15절 #7) |

### 게임 요소

| 요소 | 설명 | 공개 범위 |
| --- | --- | --- |
| 손패 | 보유 중인 카드 | 내용은 소유자만 / 장수는 공개 |
| 덱 | 아직 뽑히지 않은 카드 | 비공개 / 잔여 장수는 공개 |
| 버림 더미 | 처리가 끝난 카드 | 공개 |
| 함정 슬롯 | 설치한 함정이 대기하는 영역 | 개수는 공개 / **종류는 비공개(뒷면)** |

## 4. 카드 타입별 요약

| 타입 | 사용 시점 | 이동 경로 |
| --- | --- | --- |
| 행동 | 자신의 턴, 메인 행동 1회 | 손패 → 사용 → 반응 대기(10초) 및 처리 → 버림 더미 |
| 함정 | 조건 충족 시 소유자 **수동** 발동 | 손패 → 설치 → 조건 충족 → 발동 선택 → 반응 대기 → 처리 → 버림 더미 |
| 카운터 | 처리 중인 카드에 반응, 언제든 | 손패 → 사용 → 반응 대기 → 처리 → 버림 더미 |

### 공통 규칙 (확정)

* 사용·발동한 카드는 처리 후 **반드시** 버림 더미로 이동한다. 무효화·불발돼도 동일하다.
* 발동하지 않은 함정 카드는 슬롯에 유지된다.
* 승인되지 않은(거절된) 요청의 카드는 원래 위치를 유지한다.

---

## 5. 행동 카드

### 사용 조건 (전부 만족)

1. 자신의 턴
2. 손패에 존재
3. 메인 행동 미사용
4. 카드별 조건 충족
5. (필요 시) 유효한 대상 존재

### 사용 규칙

* 사용 시점에 **대상이 확정**된다. 처리 중 변경·재선택 불가.
* 현재 처리 카드로 등록되고 **10초 반응 시간**이 시작된다. (대응 카드 보유 여부와 무관하게 항상 10초)
* 행동 카드 사용과 드로우는 **둘 중 하나만** 가능하다.
* 모든 함정·카운터 처리가 끝난 뒤 턴이 종료된다. **무효화·불발돼도 턴은 종료된다.**

---

## 6. 함정 카드

### 설치 조건 (전부 만족)

1. 자신의 턴
2. 메인 행동 미사용
3. 손패에 존재
4. 빈 함정 슬롯 존재

### 설치 규칙

* 플레이어당 **최대 3장**.
* 자신의 턴에 빈 슬롯 수만큼 **여러 장** 설치할 수 있다.
* 설치는 **메인 행동으로 처리하지 않는다.** 설치 후에도 추가 설치와 메인 행동이 가능하다.

### 노출 규칙

* 슬롯 **존재 여부와 개수는 공개**.
* 카드 **종류는 비공개**(뒷면 표시).
* 발동하는 순간 공개된다.

### 발동 규칙

* 자신의 턴이 아니어도 발동할 수 있다.
* 조건이 맞으면 **자동 발동한다** — 소유자 입력은 설치뿐. 판정은 방장 (확정 2026-11-08, PM).
* 함정 조건은 **「다른 사람이 나에게 X 한 뒤」** 사건형이다. 그 사건이 일어난 체인이 끝난 뒤 발동한다. 막기(무효화)는 함정이 아니라 카운터가 한다 (2026-11-08, PM).
* 발동 중 누가 고르는 입력이 없다 — 고를 것이 있으면 무작위 · 고정값으로 정한다 (2026-11-08, PM).
* 발동한 함정은 공개 후 현재 처리 카드로 등록되고 10초 반응 시간이 시작된다 (연출 시간 뒤, 8절). 체인이 없으면 새 체인의 맨 아래가 된다.
* 처리 후 효과 적용·무효화·불발 여부와 관계없이 버림 더미로 이동한다.
* 사망 대기 중인 플레이어는 「본인 사망 대기」 함정만 발동할 수 있다 (`06` 3절).

### 발동 시점 (2026-11-06)

> **2026-11-08 자동 발동 확정으로 이 절은 다시 쓴다.** 아래 표 · 「함정 시간」 · 「여러 함정 동시 발동」은 소유자가 직접 내던 때의 규칙이고, T 번호는 옛 목록 기준이다. 자동 발동에서는 「카드 반응」(반응 시간) · 「HP 이하」 · 「찹츄 존재」 같은 반응형 · 상태형 조건을 두지 않는다. 여럿이 동시에 맞을 때의 순서는 **미정** (15절 #3).

함정마다 카드 데이터에 **발동 조건 종류** 하나를 둔다. 종류별로 낼 수 있는 때가 다르다.

| 종류 | 조건 | 낼 수 있는 때 | 카드 |
| --- | --- | --- | --- |
| 카드 반응 | 체인 맨 위 카드의 종류(행동 / 함정 / 카운터)가 함정의 「반응 대상」에 있다 | 반응 시간 (카운터와 같다, 7 · 8절) | T03 · T05 |
| 피해 받은 후 | 직전 체인에서 **다른 플레이어에게** 피해를 받았다 | 함정 시간 (아래) | T06 · T07 |
| HP 이하 | 본인 HP 가 카드 값(N) 이하 | 조건이 맞는 동안 언제든 — 체인이 있으면 반응 시간에, 없으면 새 체인 | T02 |
| 본인 사망 대기 | 본인이 사망 대기 중 | 사망 대기 동안 (`06` 8절) | T01 · T17 |
| 찹츄 존재 | 나 아닌 찹츄 상태 플레이어가 있다 | 조건이 맞는 동안 언제든 | T04 |
| 훔쳐진 후 | 직전 체인에서 다른 플레이어가 내 손패를 가져갔다 | 함정 시간 | T08 |
| 버려진 후 | 직전 체인에서 다른 플레이어의 효과로 내 손패가 버려졌다. 버려진 장수를 함정 효과가 쓴다 | 함정 시간 | T09 |
| 함정 파괴된 후 | 직전 체인에서 다른 플레이어가 내 설치 함정을 파괴했다 | 함정 시간 | T10 |
| 내 함정 무효된 후 | 내가 발동한 다른 함정이 카운터로 무효화됐다 | 함정 시간 | T12 |
| 카드 반환된 후 | 행동 카드가 시전자 손패로 반환됐다 (C01). 누구의 함정이든 | 함정 시간 | T13 |
| 여러 장 뽑은 후 | 다른 플레이어가 카드 효과로 한 번에 N장(카드 값) 이상 뽑았다 | 함정 시간 | T14 |
| 턴 스킵된 후 | 내 턴이 스킵됐다 | 스킵 직후의 함정 시간 | T15 |
| 찹츄 부여된 후 | 다른 플레이어가 나에게 찹츄 상태를 부여했다 | 함정 시간 | T16 |

* 「~한 후」 조건(피해 · 훔침 · 버림 · 파괴 · 무효 · 반환 · 여러 장 · 스킵 · 찹츄 부여)은 그 사건 한 번에 함정 한 번이다 — 발동하면 그 사건 기록은 쓴 것이 된다 (2026-11-06).
* T11(함정이 공개된 후)은 공개하는 효과가 카드 목록에 없어 종류를 두지 않는다 (C14 와 함께 보류, `11-card-list` 5-1).
* **함정 시간** — 체인을 처리한 뒤(턴 스킵이면 스킵 직후), 「~한 후」 조건이 맞는 함정을 가진 사람이 있으면 마스터가 후처리 연출 뒤 **5초** 함정 시간을 연다. 없으면 열지 않는다 (누군가 반응할 함정을 가졌다는 것은 드러난다 — 2026-11-06 PM 확정). 함정 시간에 함정이 나오면 그 체인을 처리한 뒤 다시 확인한다. 아무도 내지 않고 끝나면 그 기회는 사라진다.
* 대상이 「발동시킨 사람」(피해를 준 · 훔친 · 버리게 한 · 파괴한 · 무효화한 · 찹츄를 준 · 카드를 낸 플레이어. 카드 반환 · 여러 장 뽑기는 그 일을 겪은 플레이어)인 함정은 대상 타입 `TriggerSource` — 마스터가 정한다.
* 「카드 반응」 함정도 카운터와 같은 **반응 조건**(7절)을 하나 갖는다 — T03 = 다른 플레이어가 낸 카드, T05 = 나를 대상으로 한 카드.
* 체인 · 함정 시간 · 사망 대기 동안 턴 제한 시간은 멈추고, 메인 행동 전이었다면 끝난 뒤 남은 시간으로 이어진다 (`03-turn` 4절).

### 효과 규칙

* 함정 효과는 **카드에 작성된 내용만** 적용한다.
* 원래 카드를 무효화하려면 효과에 **무효화가 명시**되어 있어야 한다. 함정 발동 자체가 무효화를 의미하지 않는다.
* 카운터로 무효화되면 해당 함정의 효과 **전체**가 미적용된다.

### 여러 함정 동시 발동

* 마스터 도착 순서로 **1개만 승인**, 나머지는 거절되어 슬롯에 유지된다.
* 승인된 함정과 그에 대한 카운터 처리를 모두 마친 뒤, 남은 함정의 발동 가능 여부를 **재확인**한다.
* 조건을 여전히 충족해도 **소유자가 다시 발동해야** 한다.

## 7. 카운터 카드

### 사용 조건 (전부 만족)

1. 반응 가능한 카드가 존재 — 체인에 카드가 있다
2. 반응 조건 충족 — 체인 **맨 위 카드의 종류**(행동 / 함정 / 카운터)가 카운터 카드의 「반응 대상」에 들어 있고, 카드마다 하나씩 둔 **반응 조건**(아래 표)이 맞는다 (2026-11-06)
3. 손패에 존재
4. **반응 시간 안**에 사용 (8절 — 연출 시간이 끝난 뒤부터 10초)
5. 맨 위 카드가 **내가 낸 카드(행동 · 카운터)가 아니다** — 내 카드에는 카운터를 쓸 수 없다 (확정 2026-11-08, PM)

### 반응 조건 (2026-11-06)

맨 위 카드(반응 대상)를 보고 판정한다. 「받는다」 = 그 카드의 효과가 나에게 들어간다(본인 무효 · 나간 사람 제외).

| 조건 | 맞을 때 | 카드 |
| --- | --- | --- |
| 아무 때나 | 반응 대상 종류만 맞으면 | C01 · C05 · C06 |
| 다른 사람의 카드 | 맨 위 카드를 낸 사람이 내가 아니다 | C02 · C04 · C07 · T03 |
| 나를 대상으로 | 다른 사람이 낸 카드이고 내가 그 카드의 대상이다 | T05 |
| 나에게 피해 | 그 카드의 피해를 내가 받는다 | C03 · C10 |
| 그 피해로 사망 | 그 카드에서 내가 받을 피해 합이 지금 HP 이상이다 (감소 · 전환 전 값) | C11 |
| 다른 사람 회복 | 그 카드의 회복을 나 아닌 사람이 받는다 | C09 |
| 내 손패를 가져가거나 버림 | 그 카드가 내 손패를 훔치거나 버리게 한다 | C08 |
| 내 함정 파괴 | 다른 사람이 낸 그 카드가 내 설치 함정을 파괴한다 | C12 |
| 내 턴 스킵 | 그 카드가 나에게 턴 스킵을 건다 | C13 |
| 나에게 찹츄 부여 | 다른 사람이 낸 그 카드가 나에게 찹츄를 준다 | C15 |

### 아래 카드를 바꾸는 카운터 (2026-11-06)

카운터는 반응한 카드(체인에서 바로 아래)에 표시를 남기고, 그 카드가 처리될 때 표시대로 바뀐다. 체인은 위에서부터 처리하므로 카운터가 먼저 처리된다 (9절). 카운터 자신이 무효화되면 표시도 남지 않는다.

| 효과 | 바뀌는 것 | 카드 |
| --- | --- | --- |
| 무효 (전체 / 본인만) | 효과 전체 미적용 / 카운터를 낸 사람만 빠짐 | C05 · C06 · C07 · C08 · C13 · C15 · T05 |
| 손패로 반환 | 효과 없이 시전자 손패로 돌아간다 (버림 더미로 가지 않는다). 행동 카드면 턴은 그대로 끝난다 (10절) | C01 |
| 대상 변경 | 대상 전체를 새 대상 1명(고른 사람 / 시전자)으로 바꾼다 — 카드에 적힌 효과라 「대상은 바뀌지 않는다」(10절)보다 앞선다 | C02 · C04 |
| 피해 → 회복 | 카운터를 낸 사람이 받을 피해를 같은 수치 회복으로 | C03 |
| 회복 → 피해 | 나 아닌 사람이 받을 회복을 같은 수치 피해로 | C09 |
| 피해 감소 | 카운터를 낸 사람이 받을 피해를 N 줄인다 | C10 |
| 사망 방지 | 카운터를 낸 사람이 그 카드의 피해로 HP 0 이 되면 HP N 으로 남는다 | C11 |
| 함정 보호 | 카운터를 낸 사람의 함정이 파괴되는 대신 손패로 돌아간다 | C12 |

### 사용 규칙

* 자신의 턴이 아니어도 사용 가능. 사용 시 반응 대상이 확정된다.
* 카운터가 등록되면 기존 카드는 **처리 대기**로 밀리고, 반응 시간이 **10초로 갱신**된다.
* 추가 카운터는 **가장 최근 카운터**를 대상으로 한다.
* 처리는 **마지막 사용 카드부터 역순**으로 진행한다.

### 동시 사용

마스터 도착 순서로 1개만 승인. 늦은 요청은 거절되어 손패에 유지된다.

## 8. 반응 시간 (확정)

* 카드가 현재 처리 카드로 등록될 때마다 **그 카드의 연출 시간(1 · 2 단계, [`10-ui.md`](10-ui.md) 5-1)이 지난 뒤** 10초가 시작된다. (대응 카드가 아무에게도 없어도 10초는 유지) (2026-11-06)
* 새 카운터가 등록되면 그 카운터의 연출 시간 뒤 10초로 **초기화**된다.
* 연출 시간은 카드 데이터에 카드마다 적힌 값이다. 마스터는 이 값으로 반응 시작 · 마감 시각을 계산해 알리고, 클라이언트의 연출이 끝나기를 기다리지 않는다 (2026-11-06).
* 반응 시간이 열리기 전(연출 중)에 도착한 카운터 요청은 거절한다 (2026-11-06).
* 10초 동안 아무도 내지 않으면 체인을 위에서부터 **한 번에** 처리한다. 처리하는 동안에는 다시 기다리지 않는다 (2026-10-30).
* 체인 길이에 **상한은 없다**. 이론상 무한이지만 카드 구성 · 수치로 실제 체인이 10장을 넘지 않게 설계한다 — 코드에 상한을 두지 않는다 (2026-11-07, PM).
* 체인을 처리한 뒤 다음 턴은 **체인 맨 아래 카드의 후처리 시간(3 · 4 단계 + 버림 더미로 이동, 카드 데이터 값)** 이 지난 뒤 시작한다 (2026-11-06, `03-turn.md` 4절). 3 · 4 단계는 체인이 끝난 뒤 효과가 적용되는 카드만 재생한다 (2026-11-08, `10-ui` 5-1 · 11절 #17).
* 모든 플레이어에게 **동일하게** 표시된다.
* 제한 시간 내 **마스터에 도착해 승인된** 요청만 인정한다. 이후 도착 요청은 거절.
* 시간 기준은 `PhotonNetwork.Time` ([`09-network.md`](09-network.md) 8절).

## 9. 처리 순서

### 9.1 카운터 체인 (역순 처리)

```
A(행동 카드) ← B(카운터, A 무효화) ← C(카운터, B 무효화)

처리 순서: C → B → A
결과:      C가 B를 무효화 → B는 A를 무효화하지 못함 → A 정상 적용
카드 이동: A, B, C 전부 버림 더미
```

### 9.2 함정 발동 시

```
기존 카드 / 게임 처리 일시 대기
   ↓
함정 등록 + 10초 반응
   ↓
함정에 대한 카운터 처리
   ↓
대기 중이던 카드로 복귀
   ↓
무효화되지 않았으면 바로 처리 (다시 기다리지 않음, 8절)
```

함정 자체가 카운터로 무효화되면 함정 효과 전체가 미적용된 뒤 동일하게 복귀한다.

### 9.3 효과가 여러 개인 카드 (2026-11-13)

* 한 카드의 효과는 적힌 순서대로 적용한다. **피해 효과 뒤에 효과가 더 있고, 그 피해로 사망 대기나 함정 시간이 생기면** 거기서 멈추고, 사망 대기(최종 사망까지) · 함정 시간(나온 함정의 체인까지)을 마친 뒤 남은 효과로 돌아간다 — `06-health` 5절 처리 순서 「HP 반영 → 사망 대기 판정 → 이후 함정·카운터 처리 → 기존 처리로 복귀」 · `11-card-list` 115.
* 그사이 최종 사망한 사람은 남은 효과를 받지도 주지도 않는다 — 그 효과만 불발 (10절).
* 다음 턴은 남은 효과까지 처리하고 그 후처리가 끝난 뒤 넘어간다.
* 코드: `GameServer.Chain.cs` `ContinueResolve` — 처리 중인 카드는 `_resolving` 에 남고, 카운터가 반응한 아래 카드는 체인에 오를 때 `ChainEntry.Below` 로 정한다.

> 이름 규칙 (2026-10-10): 개인전이라 "적(Enemy)" 대신 "나를 뺀 사람(Other)" 으로 쓴다. 카드 에셋에는 순서 번호로 저장되므로 **순서를 바꾸거나 중간에 끼우지 않는다** — 새 타입은 끝에 추가한다.

| `ChapchuPlayers` | 찹츄 상태 플레이어 전원 (나 포함) | 자동 — A02 (2026-11-06) |
| `ChapchuOthers` | 나를 뺀 찹츄 상태 플레이어 전원 | 자동 — T04 (2026-11-06) |
| `MoreHandThanMe` | 나보다 손패가 많은 모든 플레이어 — 이 카드를 낸 뒤의 내 장수와 비교 | 자동 — A23 (2026-11-06) |
| `OneAny` | 나를 포함한 1명 | 플레이어 탭 (나도 고를 수 있음) — 핥아주기 (2026-11-08) |
| `TwoAny` | 나를 포함한 2명 | 플레이어 2회 탭 (나도 고를 수 있음) (2026-11-08) |
| `MostHand` | 손패가 가장 많은 1명 (나 포함) — 내 장수는 이 카드를 낸 뒤의 값, 동률이면 방장이 무작위. 낼 때 정해 카드 공개와 함께 알린다 | 자동 — 무야호 118 (2026-11-12) |
| `NextPlayer` | 턴 진행 방향(`03-turn` 6절 #4)으로 다음 차례 1명 — 낼 때 정해 카드 공개와 함께 알린다. 나밖에 없으면 대상 0명이라 거절 | 자동 — 얼음! 120 (2026-11-13) |

카드 목록의 나머지 대상은 위 타입으로 쓴다 (2026-11-06).

* **대상 후보 조건** (2026-11-12): 고르는 타입(`OneOther` · `TwoOthers` · `OneAny`)은 카드별 「추가 사용 조건」(`11-card-list` 1-2)에 맞는 사람만 고를 수 있다 — 손패 1장 이상(`HasHand`, 102) · HP < 최대(`HpBelowMax`, 106) · 설치 함정 1장 이상(`HasTrap`, 104). 맞지 않는 사람을 고르면 방장이 거절하고 카드는 손패에 남는다 (5절 4 · 5, 10절).

* 본인 + 다른 플레이어 선택 (A11) — `OneOther`. 「본인과 대상의 손패 교환」 효과가 본인을 포함한다.
* 생존한 모든 플레이어 (A14) = `Everyone`, (T01 — 사망하는 본인 제외) = `AllOthers`. 대상 후보는 언제나 게임에 남은 사람이다.
* 카드(현재 함정 · 현재 카운터 · 파괴될 본인 함정 — C06 · C07 · C12) — 카운터의 대상은 언제나 반응한 카드라 대상 타입은 `None`. 무엇을 바꾸는지는 효과가 정한다 (7절 「아래 카드를 바꾸는 카운터」).
