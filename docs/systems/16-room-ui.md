# 16. 방 화면 UI (크기 · 배치)

**최종 수정일**: 2026-09-25
**분류**: MVP
**출처**: 이 문서가 원본. 규칙은 [`08-room.md`](08-room.md) 5절(2026-09-25 확정), 화면 규격은 [`15-screen.md`](15-screen.md)
**디자인**: 없음 — 타이틀 · 로비와 같은 스타일(배경 키 아트 · `PillButton` · 둥근 박스 · 학교안심 폰트)로 먼저 만든다. 디자인이 나오면 크기 · 배치는 유지한 채 색 · 스프라이트만 바꾼다.

---

## 1. 목적

방장이 게임을 시작하기 전 대기하는 화면. 방 코드를 알려 주고, 누가 들어와 있는지 보여 준다.

## 2. 판정 주체

표시는 전부 로컬. 시작은 방장만 요청할 수 있고, 실제 씬 전환은 `PhotonNetwork.LoadLevel`(방장)이 전원에게 전파한다.

## 3. 핵심 규칙

| # | 규칙 | 구분 |
| --- | --- | --- |
| 1 | 화면에는 **동작하는 기능만** 둔다 — 설정 · 친구 초대 · 준비 버튼 없음 (08-room 5절 #6 · #7, 14-lobby-ui 3절 #1) | 확정 |
| 2 | 방장에게만 **게임 시작** 버튼이 보인다. 최소 인원(2명) 전에는 비활성 | 확정 (08-room #1 · #2) |
| 3 | 방장이 나가면 위임 — `(방장)` 표기 · 시작 버튼이 즉시 갱신된다 | 확정 (08-room #5) |
| 4 | 로그는 입장 · 퇴장 · 방장 교체 3종, 최대 30줄 | 확정 (08-room #4) |
| 5 | 플레이어 칸은 4개 고정(최대 인원). 빈 칸은 "대기 중" | 확정 |

## 4. 주요 수치

### 4-1. 캔버스

`15-screen.md` 3절 — 1920 × 1080 · Expand · 가로 고정. 가장자리 UI 는 `SafeArea` 아래.

> 아래 px 값은 전부 **1920 × 1080 캔버스 좌표**다. 폰(가로, 화면 높이 ≈ 390pt)에서는 캔버스 1 ≈ 0.36pt.

### 4-2. 크기 기준 (모바일 가독성)

터치 44pt(캔버스 122) 이상, 글자 11pt(캔버스 30) 이상.

| 요소 | 캔버스 값 | 폰 실제 크기 | 구분 |
| --- | --- | --- | --- |
| 게임 시작 버튼 | 480 × 200 · 글자 56 | ≈ 173 × 72pt · 20pt | 확정 (로비 메인 버튼과 동일) |
| 나가기 버튼 | 320 × 120 · 글자 40 | ≈ 115 × 43pt · 14pt | 확정 |
| 방 코드 | 글자 96 (B) | ≈ 35pt | 확정 |
| 인원 | 글자 48 | ≈ 17pt | 확정 |
| 플레이어 칸 | 400 × 400 · 이름 44 · `(방장)` 32 | 이름 ≈ 16pt | 확정 |
| 로그 | 글자 28 (R) · 최대 30줄 중 보이는 만큼 | ≈ 10pt (보조 정보라 예외) | 확정 |

## 5. 입력

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| 게임 시작 탭 | 방을 닫고(`IsOpen · IsVisible = false`) `PhotonNetwork.LoadLevel(GameScene)` | 방장 · 인원 ≥ 2 |
| 나가기 탭 | `NetworkManager.LeaveRoom()` → 들어온 씬으로 복귀 (`SceneFlow.ReturnSceneAfterRoom`) | 항상 |

## 6. 화면 상태

| 현재 | 조건 | 다음 | 화면 변화 |
| --- | --- | --- | --- |
| 대기 | 입장 · 퇴장 · 방장 교체 (`RoomEvents`) | 대기 | 칸 · 인원 · 시작 버튼 · 로그 갱신 |
| 대기 | 시작 탭 (방장) | — | 전원 `GameScene` |
| 대기 | 나가기 탭 | — | 로비(또는 디버그 로비) |

## 7. 화면 구성

```
┌──────────────────────────────────────────────────────────────┐
│ [나가기]              방 코드  ABCD                    2 / 4  │
│                                                              │
│      ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐          │
│      │  닉네임 │  │  닉네임 │  │ 대기 중 │  │ 대기 중 │          │
│      │ (방장) │  │        │  │        │  │        │          │
│      └────────┘  └────────┘  └────────┘  └────────┘          │
│                                                              │
│ 로그 (3줄 정도)                 [게임 시작]  (방장만)          │
└──────────────────────────────────────────────────────────────┘
```

| UI | 표시 조건 | 표시 내용 | 동작 | 구분 |
| --- | --- | --- | --- | --- |
| 나가기 버튼 | 항상 | "나가기" | 5절 | 확정 |
| 방 코드 | 항상 | "방 코드" 라벨 + 코드 4자 | — | 확정 |
| 인원 | 항상 | `n / 4` | — | 확정 |
| 플레이어 칸 × 4 | 항상 | 닉네임, 방장이면 아래에 "(방장)". 빈 칸 "대기 중" | — | 확정 |
| 게임 시작 버튼 | **방장만** | "게임 시작" | 5절. 인원 < 2 이면 비활성 | 확정 |
| 로그 | 항상 | "○○님이 입장했습니다." · "퇴장했습니다." · "방장이 되었습니다." | — | 확정 |

### 7-1. 배치

| 요소 | 크기 | 앵커 · 위치 | 구분 |
| --- | --- | --- | --- |
| 나가기 버튼 | 320 × 120 | 좌상단 (48, 48) — SafeArea | 확정 |
| 방 코드 묶음 | 라벨 40 + 코드 96, 세로 | 상단 중앙, 위 48 — SafeArea | 확정 |
| 인원 | 글자 48 | 우상단 (48, 48) — SafeArea | 확정 |
| 플레이어 칸 줄 | 4 × (400 × 400), 간격 40 → 1720 × 400 | 화면 중앙, 위로 40 (y = +40) | 확정 |
| 게임 시작 버튼 | 480 × 200 | 하단 중앙, 아래 72 | 확정 |
| 로그 | 640 × 200 | 좌하단 (48, 48) — SafeArea | 확정 |

| 스타일 | 값 |
| --- | --- |
| 버튼 | `PillButton` 프리팹 (타이틀 접속 버튼과 동일: 반경 22 · `#B18AE0` · 테두리 5 `#FFFDF8` · 그림자 · 호버/누름) |
| 플레이어 칸 | 반경 32 둥근 박스, 배경 `#FFFDF8` 92%, 테두리 4 `#B18AE0` (입력창과 동일 계열). 빈 칸은 배경 40% |
| 글자 | 코드 · 이름 · 버튼 = 학교안심 둥근미소 B, 로그 · "(방장)" · "대기 중" = R. 밝은 배경 위는 `#5B3E8C`, 배경 위는 `#FFFDF8` |
| 배경 | 타이틀과 같은 키 아트 + 세로 오버레이 |

RoomCanvas             [RoomView · RoomPresenter]  1920×1080 · Expand

| 스크립트 | 역할 |
| --- | --- |
| `UI/RoomScreen/RoomView` | 표시 setter(`SetRoomCode` · `SetPlayerCount` · `SetPlayers` · `SetStartButton` · `AddLog`)와 버튼 이벤트(`StartRequested` · `LeaveRequested`). 네트워크를 모른다 |
