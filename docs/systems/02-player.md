# 02. 플레이어 · 좌석

**최종 수정일**: 2026-11-08
**분류**: Core
**봇**: 이 문서의 「플레이어」 는 봇([`18-bot.md`](18-bot.md)) 을 포함한다. 봇은 `actorNumber` 대신 방장이 부여하는 식별자를 가지며, 나머지 속성 · 공개 범위는 같다.

---

## 1. 목적

방에 입장한 각 플레이어의 식별, 좌석 배치, 상태 데이터를 관리한다.

| 속성 | 타입 | 기본값 | 원본 소유 | 공개 범위 | 구분 |
| --- | --- | --- | --- | --- | --- |
| `actorNumber` | int | Photon 발급 | Photon | 전체 | 확정 |

## 3. 좌석 배치

### 규칙 (확정)

1. 자신은 **항상 0번 자리**(화면 하단)에 배치한다. 모든 클라이언트에서 동일하게 동작한다.
2. 나머지 플레이어는 `actorNumber` 오름차순으로 정렬해 배치한다. 봇은 **사람 뒤에 봇 번호 순** (제안, `18-bot` 8-3).

| 인원 | 배치 (인덱스) |
| --- | --- |
| 2명 | 상대 1명 → 2번 자리 (인덱스 2, 정면) |
| 3명 | 상대 2명 → 1번, 2번 자리 |
| 4명 | 상대 3명 → 1번, 2번, 3번 자리 |

### 구현 요구사항

* 좌석 배치는 **각 클라이언트가 로컬에서 계산**한다. 네트워크로 전송하지 않는다.
* 같은 입력(내 actorNumber + 참가자 목록)이면 항상 같은 결과가 나와야 한다.
* 좌석 계산은 **한 곳에서만** 수행하고, 손패 UI와 플레이어 정보 UI가 그 결과를 공유한다.

> 계산은 `OpponentSeatsPresenter`(GameScene 의 OpponentSeats) 한 곳 — `GetOpponentSeatIndices` + actorNumber 오름차순. 상대 손패 부채꼴 등은 이 결과를 받아 쓴다 (2026-11-03). 옛 `SeatManager` · `HandSeatManager` 이중 호출은 사라짐.

## 4. 상태 흐름 (생존 상태)

```
Alive → (HP 0) → DeathPending → (대응 처리) → Alive 복귀
                                            → Dead (최종 사망)
```

상세 규칙은 [`06-health.md`](06-health.md).

## 5. UI

| UI 요소 | 표시 조건 | 표시 내용 | 갱신 시점 |
| --- | --- | --- | --- |
| 닉네임 | 항상 | 닉네임 | 입장 시 1회 |
| HP 텍스트 | 항상 | `현재 HP / 100` | HP 변경 브로드캐스트 |
| HP 게이지 | 항상 | 비율 바 | HP 변경 브로드캐스트 |
| 손패 장수 | 항상 | 숫자 | handCount 변경 |
| 함정 슬롯 | 항상 | 슬롯 개수 + 뒷면 카드 | trapCount 변경 |
| 턴 표시 | 자신의 턴일 때 | 프로필 초록색 외곽선 | 턴 변경 |
| 사망 대기 | DeathPending | **표시하지 않는다** — HP 0 만 (`10-ui` 3절, 확정 2026-11-08 PM) | — |
| 최종 사망 | Dead | 영역 비활성 + "사망" | 상태 변경 |
| 찹츄 표시 | isChapChu | 찹츄 아이콘 | 상태 변경 |

상세는 [`10-ui.md`](10-ui.md).

## 6. 예외

| 상황 | 처리 | 구분 |
| --- | --- | --- |
| 게임 중 퇴장 (나가기) | 좌석 UI 제거, 턴 순서·대상 후보에서 제외 | 확정 |
| 연결 끊김 후 재접속 | 게임은 멈추지 않는다. 끊긴 사람의 **자리 · 손패 · 함정 · HP 는 그대로 유지**되고, 그 사람의 턴은 20초 시간 초과로 넘어간다. 연속 3턴 시간 초과면 강제 퇴장(최종 사망, `03-turn`). 돌아오면 **방장이 전체 스냅샷을 다시 보내** 자리 · 손패 · 함정 · HP 를 전부 복원한다. 좌석은 3절 규칙으로 다시 계산하므로 같은 자리가 나온다. 규칙 본문은 [`09-network.md`](09-network.md) 재접속 절이 기준 | 확정 (2026-11-07) |
| 중도 난입 | 허용하지 않음 | **가정** (현재 코드가 전제하고 있음) |
| 남은 플레이어가 1명 | 승리 판정. 연쇄가 모두 끝난 뒤 판정 (`07` 3절) | 확정 |
