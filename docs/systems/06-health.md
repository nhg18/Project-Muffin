# 06. 체력 · 사망

**최종 수정일**: 2026-09-25
**분류**: Core

---

## 1. 목적

피해·회복·사망 처리를 정의한다. **모든 HP 변경은 마스터가 최종 확정한다.**

---

## 2. 핵심 수치

| 항목 | 값 | 구분 |
| --- | --- | --- |
| 초기 / 최대 HP | **100 (정수)** | 확정 |
| 위험 상태 | HP 1~20 | 확정 |
| 사망 조건 | HP 0 | 확정 |
| 사망 대기 대응 시간 | 5초 | 확정 |

* 피해로 HP가 0 미만이 되어도 최종 HP는 **0**.
* 회복으로 최대치를 초과해도 최종 HP는 **100**.
* 최대 HP를 변경하는 카드가 생기기 전까지 전원 최대 HP는 100 고정.

> HP 는 코드 전체에서 `int` 다. 2026-09-24 통일 완료.

---

## 3. 생존 상태

| 상태 | 설명 | 행동 가능 여부 |
| --- | --- | --- |
| `Alive` | HP 1 이상 | 정상 행동·카운터·함정 사용 가능 |
| `DeathPending` | HP 0, 사망 관련 처리 대기 중 | **사망 관련 함정·카운터만** 사용 가능 |
| `Dead` | 모든 사망 대응 후에도 HP 0 | 게임 행동 불가, 관전 전환 |

```
Alive → (HP 0) → DeathPending → 사망 관련 카드 연쇄 처리 →  HP 1 이상 → Alive 복귀
                                                        →  HP 0     → Dead (최종 사망)
```

---

## 4. HP 변경 공통 규칙 (확정)

1. 모든 변경에 **효과 출처 · 사용자 · 대상 · 종류 · 기본 수치**를 기록한다.
2. 피해 감소·무효화·전환을 **모두 계산한 뒤 HP에 한 번만** 반영한다. 중간값을 HP에 쓰지 않는다.
3. 최종 피해·회복이 **0이면 해당 사건 자체가 발생하지 않는다.** (관련 함정도 발동하지 않음)
4. 효과가 불발돼도 카드의 사용·버림·턴 소비는 정상 처리된다.

### 처리 순서

```
카드 등록 → 5초 반응 → 선행 함정·카운터 처리 → 최종 피해/회복 계산
→ HP 반영 → 위험 상태 / 사망 대기 판정 → 이후 함정·카운터 처리 → 기존 처리로 복귀
```

---

## 5. 피해 처리

| 규칙 | 내용 |
| --- | --- |
| 차감 | 현재 HP에서 최종 피해량 차감 (0 미만 불가) |
| 무효화 | HP 변경 없음 |
| 자해 | 자신이 사용한 카드로 자신이 피해를 받으면 자해로 기록 |
| 전환 | 피해를 동일 수치 회복으로 전환하면 피해 미적용, **회복 사건으로 처리** (C03) |

---

## 6. 회복 처리

| 규칙 | 내용 |
| --- | --- |
| 가산 | 현재 HP에 최종 회복량 가산 (최대치 초과분 미적용) |
| 최대 HP 상태 | 실제 회복량 0 → 사건 미발생 |
| 최종 사망 플레이어 | **일반 회복 대상이 될 수 없다** |
| 사망 대기 플레이어 | `생존 / 부활 / 사망 방지`가 **명시된 효과로만** 회복 가능 |
| 흡수 효과 | 대상 HP-N 후 본인 HP+N. 카드에 작성된 순서로 처리. 명시 없으면 피해·회복을 독립적으로 처리 (A19) |

---

## 7. 위험 상태 판정

| 규칙 | 내용 |
| --- | --- |
| 발생 조건 | **피해로** 최종 HP가 1~20이 되었을 때 |
| 미발생 | 회복으로 HP가 20 이하가 된 경우 |
| 우선순위 | HP 0이면 위험 상태보다 **사망 대기 판정이 우선** |

처리: `HP 확정 → 위험 상태 표시 → 조건 충족 함정 발동 기회 → 함정·카운터 처리 → 조건 재확인 → 기존 처리 복귀`

관련 카드: T02(HP 20 이하 시 발동 가능)

---

## 8. 사망 대기

| 규칙 | 내용 |
| --- | --- |
| 진입 | HP 0이 되면 즉시 제거하지 않고 사망 대기로 전환. **턴·게임 처리 일시 정지** |
| 대응 시간 | 5초 |
| 사용 가능 카드 | 사망 관련 함정·카운터만 |
| 발동 가능 효과 | HP N으로 생존 / 사망 방지 / 부활 / 사망 시 마지막 효과 |
| 다중 함정 | 생존 함정을 먼저 써서 HP가 1 이상이 되면 **남은 사망 함정은 사용 불가** |

처리: `HP 0 → 사망 대기 등록 → 대응 5초 → 함정/카운터 사용 및 연쇄 처리 → 재확인 → 생존 복귀 또는 최종 사망`

관련 카드: T01(사망 시 전원 피해), T17(손패·함정 모두 버리고 HP N 생존), C11(피해는 받되 HP N 생존)

---

## 9. 최종 사망

사망 대응이 끝난 뒤에도 HP 0이면:

| 처리 | 내용 |
| --- | --- |
| 목록 제거 | 생존 목록 · 턴 순서 · 대상 후보에서 제거 |
| 카드 | 손패 · 설치 함정 **전부 버림 더미로** 이동 |
| 화면 | 관전 전환. 최종 HP 0, 손패·함정 슬롯 0으로 표시 |

---

## 10. 카드 처리 중 사망

| 상황 | 처리 |
| --- | --- |
| 카드 **사용자**가 처리 중 사망 | 이미 승인된 카드는 **끝까지 처리** (생존 조건이 명시된 카드만 불발) |
| 카드 **대상**이 처리 전 사망 | 기존 대상 유지, 해당 효과만 불발. 다른 대상은 계속 처리 |

---

## 11. 다중 대상과 동시 사망

| 상황 | 처리 |
| --- | --- |
| 여러 대상에게 같은 효과 | **변경 전 HP 기준**으로 전원 계산 후 한 번에 갱신 |
| 여러 명이 동시에 HP 0 | 전원 사망 대기 등록 → 마스터 승인 순서로 사망 함정 처리 → 모든 대응 후 남은 HP 0 플레이어를 **함께** 최종 사망 |

> ⚠ 현재 `CardData.PlayCard`는 대상별로 효과를 순차 실행한다. "변경 전 HP 기준 일괄 계산"을 만족하지 못한다.

---

## 12. 턴 처리 연동

| 상황 | 처리 |
| --- | --- |
| 현재 턴 플레이어 사망 확정 | 해당 턴 종료 후 다음 생존 플레이어로 이동 |
| 다른 플레이어 사망 | 처리 후 기존 턴 플레이어 진행으로 복귀 |
| 최종 사망 / 사망 대기 | 턴 순서에서 제외 (연결 종료와는 **별도 상태**로 기록) |

---

## 13. UI

| 상태 | 표시 |
| --- | --- |
| 정상 | 현재 HP / 최대 HP |
| 위험 | HP·게이지 경고색 |
| 사망 대기 | "사망 대기" 문구 + 대응 시간 |
| 최종 사망 | 플레이어 영역 비활성화 + "사망" 표시 |

* HP 변경 애니메이션은 **마스터 최종 결과 수신 후** 재생한다.
* 확정 전 HP를 최종 수치처럼 표시하지 않는다.

---

## 14. 서버 처리 및 데이터

* 클라이언트는 **카드 사용·대상 선택만 요청**한다.
* 마스터가 소유권·조건·대상·현재 HP·처리 순서를 검증한 뒤 최종 HP를 변경한다.
* **처리 ID**로 중복 적용을 방지한다.

### HP 변경 기록 항목

처리 ID · 효과 카드 ID · 효과 사용자 · 대상 · 변경 전/후 HP · 기본 변경량 · 최종 변경량 · 카운터/함정 적용 내역 · 처리 시각

---

## 15. 예외 처리 요약

| 상황 | 처리 |
| --- | --- |
| 대상이 처리 전 최종 사망 | 해당 효과 불발 |
| 피해·회복량 0 | 사건 미발생, 관련 함정 미발동 |
| HP 0에서 일반 회복 | 불발 |
| HP 0에서 생존·부활 효과 | HP N 적용 후 생존 복귀 |
| 다중 대상 중 일부만 사망 | 생존 대상 효과는 계속 처리 |
| 모든 플레이어 최종 사망 | 무승부 |

## 16. 현재 구현 상태

| 항목 | 상태 |
| --- | --- |
| 초기 HP 100 | `GameStatus.MaxHp = 100` (int). 단, 프로퍼티 초기 기록은 **모든 클라이언트가 모든 좌석의 HP 를** `PlayerPresenter.Init` 으로 기록한다 (마스터 일괄 초기화 아님) |
| HP UI 텍스트 / 게이지 | UI 컴포넌트는 있으나 **갱신되지 않음** |
| `DamageEffect` 클래스 | 마스터에서 `StatBuffer.Get/Set` 으로 HP 를 빼고 `Commit` 이 프로퍼티에 기록한다 |
| **피해 적용** | 부분 — 단순 차감만. 감소 · 무효 · 전환을 모은 뒤 1회 반영(4절), 처리 ID, 다중 대상 일괄 계산은 없음 |
| 회복 | **미구현** |
| 위험 상태 | **미구현** |
| 사망 대기 | **미구현** |
| 최종 사망 | **미구현** |
| 마스터 검증 | **미구현** |
| HP Photon 프로퍼티 | `PlayerProps.Hp` 로 통일. `PlayerPresenter` 가 읽어 `GameEvents.OnHpChanged` 를 올리지만 **좌석 UI 가 구독하지 않는다** |
| HP 변경 기록 | **미구현** |
