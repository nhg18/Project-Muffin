# 06. 체력 · 사망

**최종 수정일**: 2026-11-22 (3 · 4 · 6 · 8 · 10 · 11 · 15절 — 체인 끝 일괄 확정 · 사망 대기는 능력이 있을 때만 · 대응 시간 삭제). 이전: 2026-11-08
**분류**: Core

---

## 1. 목적

피해·회복·사망 처리를 정의한다. **모든 HP 변경은 마스터가 최종 확정한다.**

---

## 2. 핵심 수치

| 항목 | 값 | 구분 |
| --- | --- | --- |
| 초기 / 최대 HP | **100 (정수)** | 확정 |
| 사망 조건 | HP 0 | 확정 |
| 사망 대기 대응 시간 | **없음** — 사망 대기에는 입력이 없어 방장이 바로 계산한다 (8절) | 확정 (2026-11-22, PM — 「5초」 삭제) |

* 피해로 HP가 0 미만이 되어도 최종 HP는 **0**.
* 회복으로 최대치를 초과해도 최종 HP는 **최대 HP**.
* 최대 HP는 기본 100. 예외는 「벌크업」(HP 2배) 하나 — 2배가 100을 넘으면 최대 HP가 그 값이 되고, 피해로 HP가 100 밑으로 내려가면 최대 HP는 100으로 돌아온다 (확정 2026-11-08, PM · 노션 카드 DB). **벌크업은 구현 제외** (사용자 2026-11-13, `11-card-list` 1-1) — 지금 게임에는 최대 HP 가 바뀌는 경우가 없다.

## 3. 생존 상태

| 상태 | 설명 | 못 하는 것 |
| --- | --- | --- |
| `Alive` | HP 1 이상. 체인 처리 중에 HP 0 이 된 사람도 **체인이 끝날 때까지는** `Alive` 다 (4절) | — |
| `DeathPending` (사망 대기) | 체인(또는 체인 밖 처리)이 끝났을 때 HP 0 이고, **사망 대기 능력**(「죽은 척」 등, 8절)이 있는 사람. 방장 안에서만 쓰는 상태 (13절) | 카드 사용(행동 · 카운터 · 함정 설치) · 함정 발동(사망 대기 능력은 빼고) · 찹츄 선언 · 턴 |
| `Dead` (최종 사망) | HP 0 인데 사망 대기 능력이 없거나, 사망 대기가 끝나도 HP 0 | 위의 전부 + 사망 대기 능력. 턴 순서 · 대상 후보에서 빠지고 관전으로 (9절) |

```
Alive → 체인 끝에 HP 0 ─ 사망 대기 능력 있음 → DeathPending → 능력으로 HP 1 이상 → Alive 복귀
                       │                                   → HP 0          → Dead
                       └ 없음 → Dead (최종 사망)
```

* 정리 시점은 체인 끝 — 순서는 `04-card` 9.2 (체인 끝 확정 → 사망 정리 → 찹츄 선언 → 함정 → 사망 대기 해소, 2026-11-22 PM).
* **미정**: `DeathPending` 인 사람이 남의 함정의 대상이 되는가 (18절 #3).

## 4. HP 변경 공통 규칙 (확정)

1. 모든 변경에 **효과 출처 · 사용자 · 대상 · 종류 · 기본 수치**를 기록한다.
2. 피해 감소·무효화·전환을 **모두 계산한 뒤 HP에 한 번만** 반영한다. 중간값을 HP에 쓰지 않는다.
3. 최종 피해·회복이 **0이면 해당 사건 자체가 발생하지 않는다.** (관련 함정도 발동하지 않음)
4. 효과가 불발돼도 카드의 사용·버림·턴 소비는 정상 처리된다.

### 처리 순서

```
카드 등록 → 반응 시간 → 체인 처리 (위에서부터 · 효과는 멈추지 않고 이어서 계산)
→ 체인 끝: 효과 한꺼번에 확정 → 사망 정리 (3 · 8절) → 찹츄 자동 선언
→ 함정 발동 (설치한 순서) → 사망 대기 해소
```

* 2026-11-15 PM: 효과 사이에서 멈추지 않는다 — 함정 · 사망 대기는 행동(체인)이 끝난 뒤 (`04` 6절 · 9.2 · 9.3).
* 2026-11-22 PM: **체인 안의 효과는 체인 끝에 한꺼번에 확정된다.** 체인 도중에 HP 0 이 된 사람도 남은 효과(일반 회복 · 빼앗기 등)를 그대로 받고, 사망 판정은 체인 끝에 한 번이다. 예: HP 10 인 사람이 「팍씨」 를 맞으면 10 피해로 HP 0 이 되고 1장도 빼앗긴 뒤, 체인 끝에 사망 정리.

## 5. 피해 처리

| 규칙 | 내용 |
| --- | --- |
| 차감 | 현재 HP에서 최종 피해량 차감 (0 미만 불가) |
| 무효화 | HP 변경 없음 |
| 자해 | 자신이 사용한 카드로 자신이 피해를 받으면 자해로 기록 |
| 전환 | 피해를 동일 수치 회복으로 전환하면 피해 미적용, **회복 사건으로 처리** (C03) |

---

## 6. 회복 처리

| 규칙 | 내용 |
| --- | --- |
| 가산 | 현재 HP에 최종 회복량 가산 (최대치 초과분 미적용) |
| 최대 HP 상태 | 실제 회복량 0 → 사건 미발생 |
| 최종 사망 플레이어 | **일반 회복 대상이 될 수 없다** |
| 사망 대기 플레이어 | `생존 / 부활`이 **명시된 사망 대기 능력으로만** 회복 가능 — 「HP 20으로 부활」(3008 죽은 척) 은 사망 대기를 끝내고 생존으로 돌린다 (전원에게 생존 복귀를 알린다, 2026-11-06). 체인 처리 중 HP 0 인 사람은 아직 사망 대기가 아니라 일반 회복을 받는다 (4절, 2026-11-22) |
| 흡수 효과 | 대상 HP-N 후 본인 HP+N. 카드에 작성된 순서로 처리. 명시 없으면 피해·회복을 독립적으로 처리 (A19) |

## 8. 사망 대기

| 규칙 | 내용 |
| --- | --- |
| 진입 | 체인(또는 빈 덱 피해 · 턴 끝 피폭 같은 체인 밖 처리)이 끝나 효과가 확정됐을 때 HP 0 이고, **사망 대기 능력이 있을 때만**. 없으면 사망 대기 없이 바로 최종 사망 (9절). 함정 줄에서 HP 0 이 된 사람도 같은 방식 (2026-11-22, PM — 「HP 0 이 되면 즉시 사망 대기」 를 대체) |
| 대응 시간 | **없다** — 사망 대기에는 입력이 없다. 방장이 사망 대기 능력 · 함정 순서를 계산해 결과를 정한다 (2026-11-22, PM — 「5초」 삭제) |
| 멈추는 것 | 턴 진행 · 턴 제한 시간 · 새 메인 행동 — 사망 대기가 해소될 때까지 |
| 못 하는 것 | 3절 표 |
| 사망 대기 능력 | 「사망한 뒤 →」 처럼 사망 때 처리하는 함정 — HP N 으로 생존 · 부활 · 사망 시 마지막 효과. 함정 줄이 아니라 이 단계에서 발동하고, **사망 원인(남의 카드 · 함정 피해 · 내 카드)을 묻지 않는다** (`04-card` 6절, 2026-11-22 PM) |
| 다중 능력 | 설치한 순서대로. 생존 능력으로 HP 가 1 이상이 되면 **남은 사망 능력은 쓰지 않는다** |
| 살아난 뒤 | HP 0 이 되기 전의 사건(받은 피해 등)은 없어진다 — 그 사람의 「~한 뒤」 함정은 그 사건으로 발동하지 않는다 (2026-11-22, PM) |

처리: `체인 끝 확정 → HP 0 이고 사망 대기 능력 있음 → 사망 대기 등록 → 찹츄 선언 · 함정 줄 → 사망 대기 능력 발동 → 생존 복귀 또는 최종 사망` (순서 전체는 `04` 9.2)

관련 카드: 3008 「죽은 척」 (사망한 뒤 → HP 20으로 부활). 옛 목록 T01 · T17 도 같은 종류. C11 은 카운터라 체인 안에서 처리한다 (`04` 7절).

## 9. 최종 사망

사망 대응이 끝난 뒤에도 HP 0이면:

| 처리 | 내용 |
| --- | --- |
| 목록 제거 | 생존 목록 · 턴 순서 · 대상 후보에서 제거 |
| 카드 | 손패 · 설치 함정 **전부 버림 더미로** 이동 |
| 화면 | 관전 전환. 최종 HP 0, 손패·함정 슬롯 0으로 표시 |

## 10. 카드 처리 중 사망

| 상황 | 처리 |
| --- | --- |
| 카드 **사용자**가 처리 중 HP 0 | 체인 처리 중에는 아무도 사망하지 않는다 — 그 사람이 낸 카드도 **끝까지 처리**한다 (4절, 2026-11-22) |
| 카드 **대상**이 처리 중 HP 0 | 대상 유지, 남은 효과를 그대로 받는다 (4절, 2026-11-22 — 「해당 효과만 불발」 을 대체) |

## 11. 다중 대상과 동시 사망

| 상황 | 처리 |
| --- | --- |
| 여러 대상에게 같은 효과 | **변경 전 HP 기준**으로 전원 계산 후 한 번에 갱신 |
| 여러 명이 동시에 HP 0 | 능력이 있는 사람은 사망 대기 등록 → 사망 대기 능력을 설치한 순서로 처리 → 끝난 뒤 남은 HP 0 플레이어를 **함께** 최종 사망 (8절) |

## 12. 턴 처리 연동

| 상황 | 처리 |
| --- | --- |
| 현재 턴 플레이어 사망 확정 | 해당 턴 종료 후 다음 생존 플레이어로 이동 |
| 다른 플레이어 사망 | 처리 후 기존 턴 플레이어 진행으로 복귀 |
| 최종 사망 | 턴 순서에서 제외 (연결 종료와는 **별도 상태**로 기록). 사망 대기는 게임이 멈춘 상태라 순서에서 빼지 않는다 |

## 13. UI

| 상태 | 표시 |
| --- | --- |
| 정상 | 현재 HP / 최대 HP |
| 사망 대기 | **표시하지 않는다** — 정상과 같은 HP 표시(0). 플레이어에게 보이지 않는 상태 (확정 2026-11-08, PM · `10-ui` 2-1) |
| 최종 사망 | 플레이어 영역 비활성화 + "사망" 표시 |

* 확정 전 HP를 최종 수치처럼 표시하지 않는다.

## 14. 서버 처리 및 데이터

* 클라이언트는 **카드 사용·대상 선택만 요청**한다.
* 마스터가 소유권·조건·대상·현재 HP·처리 순서를 검증한 뒤 최종 HP를 변경한다.
* **처리 ID**로 중복 적용을 방지한다.

### HP 변경 기록 항목

처리 ID · 효과 카드 ID · 효과 사용자 · 대상 · 변경 전/후 HP · 기본 변경량 · 최종 변경량 · 카운터/함정 적용 내역 · 처리 시각

### 보관 범위

| 항목 | 규칙 | 구분 |
| --- | --- | --- |
| 보관 기간 | **게임 1판.** 방장 메모리에만 두고, 게임이 끝나 결과 화면으로 넘어가면 버린다 (2026-11-17 — 전에는 「방으로 돌아가면」) | 확정 (2026-11-07) |
| 영구 저장 | **없음.** 서버 · 기기 어디에도 저장하지 않는다. 누적 통계(승패 · 피해량 등)는 [`07-win-condition.md`](07-win-condition.md) 결과 · 통계 절이 따로 정한다 | 확정 (2026-11-07) |
| 쓰는 곳 | 중복 적용 방지(처리 ID) · 인게임 기록 서랍(`10-ui`) · 재접속 복원(`09-network`) | 확정 |
