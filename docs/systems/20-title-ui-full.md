**출처**: 2026-11-03 플랜 세션. [`12-title-ui.md`](12-title-ui.md)(배경 · 로고 · 연결 상태 · 팔레트는 그대로 잇는다) · [`store-release.md`](../store-release.md) 결정 3(로그인 방식 · 계정 삭제 · Sign in with Apple) · [`17-lobby-ui-full.md`](17-lobby-ui-full.md) 0절 레퍼런스
**전제**: 로그인 문서(미작성)가 먼저다. 이 문서는 **로그인 수단 = 게스트 · Google · Apple(iOS)**, **백엔드 = Unity Gaming Services Authentication** 을 `가정` 하고 쓴다. 수단이 바뀌면 7-3 · 6절만 고치면 되게 짰다.

> 타이틀이 하는 일이 **"닉네임 입력"** 에서 **"로그인"** 으로 바뀐다. 닉네임은 **첫 로그인 때 한 번** 정하고 그 뒤에는 서버에 저장된 것을 쓴다 (바꾸는 곳은 로비 프로필 팝업, 17 5-2). 두 번째 실행부터는 **자동 로그인**으로 타이틀을 거의 보지 않고 로비로 간다.

---

## 1. 목적

앱의 첫 화면. 서버에 연결하고, 로그인하고, 처음이면 닉네임을 정한 뒤 로비로 보낸다. 플레이어가 여기서 머무는 시간은 **자동 로그인이면 2초 안팎**, 처음이면 수단 고르기 + 닉네임 입력뿐이다.

## 2. 판정 주체

| 대상 | 판정 · 저장 | 타이틀이 하는 일 |
| --- | --- | --- |
| 서버 연결 · 연결 실패 사유 | 네트워크 서버 (12-title-ui 2절 그대로) | 표시 · 다시 시도 |
| 로그인 성공 · 실패 · 세션 유지 | **로그인 서버(백엔드)** | 요청 · 결과 표시. 토큰은 기기에 저장 |
| 닉네임 검증 (길이 · 문자) | **로컬** (12-title-ui 4-2 규칙 그대로) | 입력 즉시 검사 |
| 닉네임 중복 · 저장 | 로그인 서버 | 요청 · 결과 표시 — 중복 허용 여부는 **미정** (12절 #2) |
| 최소 버전 · 점검 | 로그인 서버의 설정 값 | 팝업 표시 — **가정** (12절 #5) |

**방장 판정 없음.** 타이틀에는 방이 없다.

## 3. 핵심 규칙

| # | 규칙 | 구분 |
| --- | --- | --- |
| 1 | 12-title-ui 3절 #6 · #7 · #8 을 잇는다 — **서버에 연결된 뒤에만** 로그인 묶음이 보이고, 연결 실패는 같은 자리에 사유 + 다시 시도, 연결이 끊긴 채로는 로비로 가지 않는다 | 확정 (기존) |
| 2 | 기기에 **로그인 정보가 남아 있으면 자동 로그인** — 로그인 묶음을 보이지 않고 로딩 묶음 "로그인 중…" 을 거쳐 바로 로비 | 제안 — 0절 레퍼런스의 가로 게임들은 타이틀에서 멈추지 않는다 |
| 3 | 자동 로그인이 **실패**하면(토큰 만료 · 서버 거절) 로그인 묶음을 보인다. 조용히 게스트로 바꾸지 않는다 | 제안 |
| 4 | 로그인 수단 버튼은 **동작하는 것만** 둔다. Apple 은 iOS 빌드에서만, Google 은 Android · PC 에서 (iOS 에 Google 을 두면 Apple 도 **필수** — store-release 결정 3) | 제안 (규칙) / 가정 (수단) |
| 5 | 닉네임 입력은 **첫 로그인(서버에 닉네임 없음)** 때만. 검증 규칙 · 에러 문구는 12-title-ui 4-2 · 10-3 그대로 | 제안 |
| 6 | 처음 시작할 때 **약관 · 개인정보처리방침 동의**를 받는다 — 닉네임 입력과 같은 화면, 동의 전에는 「시작」 이 눌리지 않는다 | 제안 — store-release 4절(방침 링크 앱 안 필수) · 문구 · 법적 요건은 미정 #4 |
| 7 | 로그인 화면의 판정은 전부 로컬 표시이고, 실패 사유는 **제목 + 설명 + 오류 코드** 형식(12-title-ui 10-5)을 로그인에도 쓴다 | 제안 |
| 8 | 터치 영역 44pt(캔버스 122) · 글자 11pt(캔버스 30) 이상 (15-screen 5절). 12-title-ui 의 ×1.7 확대 방식 대신 **캔버스 값을 직접** 정한다 | 제안 — 수치는 7절 |
| 9 | 타이틀에는 **설정 · 사운드 버튼을 두지 않는다** — 로비 설정 팝업에서 (17 7-4). 12-title-ui 미정 #1 을 이렇게 닫는다 | 제안 |
| 10 | 로그아웃 · 계정 삭제 뒤 타이틀로 돌아오면 **로그인 묶음** 상태로 (자동 로그인 안 함) | 제안 |

## 5. 입력

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| 「게스트로 시작」 탭 | 기기 고유 계정으로 로그인 요청 → 로그인 중 | 로그인 선택 |

| OS 로그인 창에서 취소 | 로그인 선택으로 복귀, 문구 없음 | 로그인 중 |
| 닉네임 입력 · 글자 입력 | 12-title-ui 5절 그대로 (카운터 n / 16, 에러 지움) | 닉네임 입력 |
| 동의 줄 탭 | 체크 토글. 「약관」 「개인정보처리방침」 글자 탭은 외부 브라우저 | 닉네임 입력 |
