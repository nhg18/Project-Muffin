# 19. 플레이어 캐릭터 · 이펙트 아이템

**최종 수정일**: 2026-11-03
**분류**: Optional — 기본 캐릭터 1종 **표시**(로비 · 룸 · 인게임 좌석)는 MVP. 캐릭터 여러 종 · 등급 · 이펙트 아이템 · 보관함은 로그인(기능 12) 뒤. 가격 · 재화 · 상점은 이 문서 밖(Future, 11절)
**출처**: 2026-11-03 PM 결정(팀 채팅) — 치장 부위 아이템 없이 **캐릭터 하나 통째** + 입장 · 사망 · 카드 디자인 · 떠 있는 파티클. 노션 「🐶 플레이어 캐릭터 · 커스터마이징」(2026-10-06, 부위 8종 악세서리 안)은 **이 문서로 대체**한다. 노션의 확정 · 합의 중 살아남는 것은 3절에 다시 적었다.

> 치장이 **게임 결과에 영향을 주지 않는다**(P2W 금지)는 「창업」 페이지 확정을 그대로 잇는다. 캐릭터 · 이펙트는 전부 **보이는 것**만 바꾼다.

---

## 1. 목적 · 범위

플레이어가 **자기 캐릭터 하나**를 고르고, 거기에 **이펙트 아이템** 넷을 달아 다른 플레이어에게 보여 준다. 캐릭터와 이펙트에는 **등급**이 있어 희소성을 만들고, 나중에 수익 모델(획득 경로 · 가격)이 여기에 붙는다.

| 포함 | 제외 (이유) |
| --- | --- |
| 캐릭터 종류 · 등급 · 기본 지급 | 부위별 악세서리(머리 · 상의 · 손 …) — **폐기** (2026-11-03) |
| 이펙트 아이템 4슬롯: 입장 · 사망 · 카드 디자인 · 오라 | 재화 · 가격 · 가챠 · 상점 · 확률 — 수익화 범위 결정 #BM-1 뒤 (11절) |
| 어디에 · 언제 보이는가 | 캐릭터별 능력 · 스탯 — 없음 (P2W 금지) |
| 보유 · 장착 · 공개 규칙 | 로그인 · 저장소 — 로그인 문서(미작성) |
| 보관함(꾸미기) 규칙 (9절) | 보관함 화면의 자리 · 크기 — [`17-lobby-ui-full.md`](17-lobby-ui-full.md) 7-6 |

## 2. 판정 주체

| 대상 | 판정 · 저장 | 비고 |
| --- | --- | --- |
| 보유 목록 · 장착 상태 | **서버(백엔드)** 가 저장. 클라이언트는 요청 · 표시 | 로그인 문서가 정하는 저장소. 로그인 전 임시 저장은 미정 #1 |
| 장착 변경 | 로비에서만, 해당 플레이어가 서버에 요청 | 방 · 게임 중에는 바꿀 수 없다 |
| 다른 플레이어에게 공개 | **방 입장 때 1회** — 캐릭터 1 + 이펙트 4 의 아이템 번호를 모두에게 공개 | 작은 공개 값. 방장 판정 없음 (외형이라 규칙이 아니다) |
| 연출 재생 | **각 클라이언트** 가 자기 화면에서 재생 | 06-health 「결과 수신 후 재생」 과 같은 원칙 — 결과는 방장, 연출은 각자 |

## 3. 핵심 규칙

| # | 규칙 | 구분 |
| --- | --- | --- |
| 1 | 캐릭터 · 이펙트는 **외형 · 연출만** 바꾼다. 체력 · 카드 · 턴 · 판정에 영향 없음 | 확정 (P2W 금지 — 「창업」) |
| 2 | 플레이어는 **캐릭터 1종**을 장착한다. 부위를 조합하지 않는다 | 확정 (2026-11-03) |
| 3 | 이펙트 아이템은 **슬롯 4개** — 입장 · 사망 · 카드 디자인 · 오라. 슬롯마다 **1개**, 비워 두면 기본 | 확정 (2026-11-03, 슬롯 4종) / 제안 (슬롯당 1개 · 기본값 규칙) |
| 4 | 캐릭터와 이펙트는 **서로 독립**이다. 어떤 캐릭터에든 어떤 이펙트든 단다 | 제안 — 캐릭터 전용 이펙트(세트)는 미정 #3 |
| 5 | 캐릭터 · 이펙트에 **등급**이 있다. 등급은 희소성과 표현 수준을 정하고, 획득 경로는 나중에 등급에 붙는다 (11절) | 확정 (등급 있음) / 제안 (등급 수 · 이름 — 4절) |
| 6 | 처음 시작한 플레이어는 **기본 캐릭터 1종 + 각 슬롯 기본 이펙트**를 가진다. 기본은 버릴 수 없다 | 제안 |
| 7 | 장착 변경은 **로비에서만**. 방에 들어간 뒤 게임이 끝날 때까지 고정 | 합의 (노션) → 제안으로 이어받음 |
| 8 | 캐릭터는 **룸 · 인게임 좌석 · 로비**에 보인다. 결과 화면은 미정 #5 | 합의 (룸 · 좌석) · 확정 (로비, 17-lobby-ui-full 3절 #2-1) |
| 9 | 획득은 **게임 재화**가 기본. 유료 · 가챠는 수익화 결정 뒤 | 확정 (노션 「게임 재화로 획득」) — 재화 자체는 이 문서 밖 |
| 10 | 모든 연출은 **상대 화면에서도 같은 아이템 번호로 같은 연출**이 난다. 내가 산 연출을 남이 본다 — 그게 이 시스템의 존재 이유 | 제안 |
| 11 | 연출은 **게임 진행을 막지 않는다** — 반응 5초 · 턴 20초 타이머는 연출과 무관하게 돈다. 입장 · 사망 연출은 그 시간 안에 끝나는 길이로 만든다 (5절) | 제안 |

## 4. 등급

| 등급 | 이름 | 표현 수준 | 수량 비율 (출시 기준) | 구분 |
| --- | --- | --- | --- | --- |
| 1 | **일반** | 정지 그림 + 대기 동작 1종. 이펙트는 단색 · 작은 파티클 | 가장 많음 | 제안 |
| 2 | **희귀** | 대기 동작 2종(숨쉬기 · 가끔 하는 동작). 이펙트는 2색 이상 · 모양 있는 파티클 | 중간 | 제안 |
| 3 | **전설** | 대기 동작 2종 + **전용 승리 동작**. 이펙트는 화면 연출(흔들림 · 번쩍임)까지 | 가장 적음 | 제안 |

- 등급 3단계는 **제안**이다. 4단계(영웅 추가)로 늘릴지는 미정 #2.
- 등급은 캐릭터와 이펙트가 **같은 사다리**를 쓴다. 표현 수준 표가 같은 등급 안에서 캐릭터 · 이펙트를 고르게 만든다.
- 기본 지급은 전부 **일반** 등급.
- "희소성" 은 지금은 **획득 난이도**로만 표현한다(게임 재화 가격 차이). 수량 한정 · 기간 한정은 미정 #4.

## 5. 이펙트 아이템 4종

| 슬롯 | 무엇 | 언제 · 어디서 재생 | 길이 · 범위 | 기본(미장착) | 구분 |
| --- | --- | --- | --- | --- | --- |
| **입장** | 내 캐릭터가 좌석에 나타나는 연출 | **게임 시작 때** 인게임 좌석에 캐릭터가 등장할 때, 4명이 좌석 순서대로 0.3초 간격 | 1인 1.0초 이내. 4명 합쳐 2초 안에 끝 → 첫 턴 시작 전 | 캐릭터가 페이드 인(0.3초) | 제안 — 룸 입장 때도 짧게 쓸지는 미정 #6 |
| **사망** | 최종 사망 때 캐릭터가 사라지는 연출 | 06-health **최종 사망(Dead)** 확정 수신 때, 그 좌석에서. 사망 대기 중에는 안 남 | 1.5초 이내. 끝나면 좌석은 관전 표시(10-ui) | 캐릭터가 회색으로 (0.5초) | 제안 |
| **카드 디자인** | 내 카드의 **뒷면** 그림 | 상대가 보는 내 손패 뒷면 · 내가 뽑을 때 날아오는 카드 · 함정 슬롯에 뒷면으로 깔린 카드 | 정지 그림 1장 (+ 전설은 은은한 반짝임) | 기본 뒷면 | 제안 — 앞면 틀은 바꾸지 않는다: 카드 종류 색(행동 파랑 · 카운터 초록 · 함정 주황, 10-ui 2-1)이 규칙 정보라 가독성을 지킨다 |
| **오라** | 캐릭터 주변에 **항상 떠 있는** 파티클 | 로비 · 룸 · 인게임 좌석에서 캐릭터가 보이는 동안 계속 | 반복. 좌석(작은 캐릭터)에서는 **작은 판**으로 — 4명 동시라 파티클 수를 좌석당 20개 이하로 | 없음 | 제안 — 성능 상한은 모바일 실기 확인 뒤 조정 |

- 입장 · 사망 연출은 **카드 연출(카드별 이펙트)과 겹치지 않는다.** 사망은 피해 연출이 끝난 뒤(06-health 순서) 시작한다.
- 연출 중에도 입력(카드 내기 · 턴 종료)은 막지 않는다 (3절 #11).
- 소리는 이펙트마다 효과음 1개를 가질 수 있다 — 소리 전체가 미정이라(기능 13) 지금은 자리만.

## 9. 보관함 (꾸미기)

로비의 **보관함 섹션**이다 — 씬 이동 · 팝업이 아니라 로비 씬 안의 전체 화면으로, 왼쪽 열 「보관함」 버튼이나 캐릭터를 탭해 연다 (17-lobby-ui-full 3절 #2-2 · 7-6). 자리 · 크기는 17 이, 여기는 **규칙**만.

| 요소 | 내용 | 구분 |
| --- | --- | --- |
| 미리보기 | 왼쪽에 지금 고른 캐릭터 전신 + 오라. 입장 · 사망 · 카드는 「재생」 버튼으로 그 자리에서 미리 본다 | 제안 |
| 소탭 | 「캐릭터」 · 「입장」 · 「사망」 · 「카드」 · 「오라」 5개 | 제안 |
| 목록 | 격자. 보유한 것은 그림, 미보유는 **잠김 표시 + 등급 표시** (획득 경로는 수익화 뒤) | 제안 |
| 등급 표시 | 틀 색으로: 일반 회색 · 희귀 보라 `#B18AE0` · 전설 금색 | 제안 |
| 장착 | 항목 탭 → 미리보기 갱신 → 「장착」 버튼 → 서버 저장. 저장 전에 섹션을 떠나면 되돌림 | 제안 |
| 상점과의 관계 | 상점 섹션은 보관함과 **같은 틀**로 미보유 품목을 보여 준다 (17 7-7). 보관함은 **보유 · 장착**, 상점은 **획득** — 같은 아이템 번호 | 제안 |
| 저장 실패 | 경고 팝업(공용) "잠시 후 다시 시도해 주세요." · 이전 장착 유지 | 제안 |

## 11. 수익 모델이 붙는 자리 (이 문서는 정하지 않는다)
