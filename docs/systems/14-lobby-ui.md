# 14. 로비 화면 UI

**최종 수정일**: 2026-11-11
**분류**: MVP
**출처**: 2026-09-25 로비 개편 결정 (플랜 세션) → 2026-11-11 「통합 화면 UI v2」 시안 (https://claude.ai/artifact/GnsoVsKiaDzipb2paoSx2B 게시본 `1794316285-7080`). 크기 · 배치 · 비주얼은 [`17-lobby-ui-full.md`](17-lobby-ui-full.md), 이 문서는 방을 만들고 참가하는 **동작**을 정한다.

> 방 생성 · 참가의 **규칙**(코드 · 인원 · 실패 처리)은 [`08-room.md`](08-room.md)가 기준이다. 이 문서는 로비 **화면**만 다룬다.

---

## 1. 목적

접속을 마친 플레이어가 방을 만들거나 참가하는 화면. 타이틀([`12-title-ui.md`](12-title-ui.md)) 다음, 방([`08-room.md`](08-room.md)) 이전.

## 2. 판정 주체

로비 화면의 판정은 전부 **로컬**이다. 버튼은 `NetworkManager`에 방 생성 · 참가를 **요청**만 하고, 결과(성공 → 방 씬 이동 / 실패 → 안내)는 Photon 콜백으로 받는다.

## 4. 주요 수치

### 4-1. 캔버스

| 항목 | 값 | 구분 |
| --- | --- | --- |
| 기준 해상도 | 1920 × 1080 | 확정 (타이틀과 동일) |
| 스케일 방식 | Scale With Screen Size · **Expand** (`15-screen.md` 3절) | 확정 |
| 화면 방향 고정 | **가로 고정** (`15-screen.md`) | 확정 (2026-09-25) |

> 아래 px 값은 전부 **1080 높이 기준 캔버스 좌표**다. 폰(가로, 화면 높이 ≈ 390pt)에서는 캔버스 1 ≈ 0.36pt.

### 4-2. 크기 기준 (모바일 가독성)

터치 영역 44pt 이상, 글자 11pt 이상 (Apple HIG. 타이틀 4-3절과 같은 기준).

| 요소 | 캔버스 값 | 폰 실제 크기 (390pt 높이 기준) | 구분 |
| --- | --- | --- | --- |
| 주 버튼 「랜덤 매칭」 | 624 × 176 | ≈ 225 × 63pt | 확정 (시안) |
| 작은 버튼 (혼자 하기 · 방 만들기 · 코드로 참가) | 각 200 × 128 | ≈ 72 × 46pt | 확정 (시안) |
| 주 버튼 글자 | 56 | ≈ 20pt | 확정 (2026-09-25) |
| 닉네임 글자 | 48 | ≈ 17pt | 확정 (2026-09-25) |

## 5. 입력

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| 랜덤 매칭 탭 | `NetworkManager.JoinRandomRoom()` 요청. 빈 방이 있으면 참가, 없으면 새 방 생성 (08-room 4절) | 항상 |
| 방 만들기 탭 | 고르는 팝업 없이 바로 `NetworkManager.CreateRoom()` 요청. 방은 **비공개**로 만들어지고, 방장이 방 안에서 공개로 바꿀 수 있다 (`08` 5절 #7) | 항상 (확정 — 시안 2026-11-11: 팝업 없음 / 기본 비공개 2026-11-07) |
| 혼자 하기 탭 | **비공개**로 방 생성 + 봇 3 추가 → 방 화면. 자동 시작하지 않는다. 방장이 방 안에서 공개로 바꿀 수 있다 (`18-bot` 10절, 2026-11-06 확정 / 비공개 생성 2026-11-07 확정) | 항상 |
| 코드로 참가 탭 | 방 코드 입력 팝업 열기 (`17` 4-3) | 항상 |
| 코드 입력 팝업 제출 | `NetworkManager.JoinRoom(code)` 요청 | 코드 입력됨 |
| 코드 입력 팝업 닫기 | 팝업 닫기, 로비 유지 | 항상 |

## 6. 화면 상태

| 현재 | 조건 | 다음 | 화면 변화 |
| --- | --- | --- | --- |
| 대기 | 랜덤 매칭 · 혼자 하기 · 방 만들기 · 코드 제출 | 요청 중 | **로딩 팝업**(도는 고리 + 글 한 줄 — 7절 표)이 뜨고 화면 입력이 전부 막힌다. 코드 입력 팝업은 제출하면 닫힌다 |
| 요청 중 | 방 참가 성공 (`OnJoinedRoom`) | — | `RoomScene`으로 이동 |
| 요청 중 | 생성 · 참가 실패 | 대기 | 로딩 팝업을 닫고 경고 팝업으로 사유 표시 |
| 요청 중 | 10초 안에 응답 없음 | 대기 | 로딩 팝업을 닫고 경고 팝업 「잠시 후 다시 시도해 주세요.」 (`08` 7절 「그 밖의 실패」 문구) — 확정 (10초, 2026-11-07) |

## 7. 화면 구성

배치는 [`17-lobby-ui-full.md`](17-lobby-ui-full.md) 7-0 · 7-1 을 따른다 — 오른쪽 아래 플레이 묶음(주 버튼 「랜덤 매칭」 + 위 줄 「혼자 하기」 「방 만들기」 「코드로 참가」).

| UI | 표시 조건 | 표시 내용 | 동작 | 구분 |
| --- | --- | --- | --- | --- |
| 닉네임 | 항상 | 타이틀에서 정한 닉네임 — 프로필 칩 안 (`17` 7-0) | — | 확정 |
| 랜덤 매칭 버튼 | 항상 | "랜덤 매칭" | 5절 | 확정 |
| 혼자 하기 버튼 | 항상 | "혼자 하기" | 5절 | 확정 |
| 방 만들기 버튼 | 항상 | "방 만들기" | 5절 | 확정 |
| 코드로 참가 버튼 | 항상 | "코드로 참가" | 5절 | 확정 (시안) |
| 방 코드 입력 팝업 | 코드로 참가 탭 | 안내 "방 코드 입력", 제출 "참가" | 5절 | 확정 |
| 실패 안내 팝업 | 생성 · 참가 · 랜덤 매칭 실패 | 제목 + 사유 | 확인 → 닫힘 | 확정 (사유 문구는 08-room 7절) |
| 요청 중 표시 | 요청 후 응답 전 | 로딩 팝업 — 도는 고리 + 아래 「…중」 글 한 줄 | 화면 입력 전부 차단. 응답(성공 · 실패)이 오면 닫힌다 | 확정 (시안, 2026-11-11) |

**요청 중 문구** (확정 2026-11-07) — 로딩 팝업의 글

| 요청 | 로딩 팝업 글 |
| --- | --- |
| 랜덤 매칭 | 찾는 중… |
| 방 만들기 · 혼자 하기 | 만드는 중… |
| 코드 입력 팝업 「참가」 | 들어가는 중… |

- 「…」 는 말줄임표 한 글자(U+2026).
- 로딩 팝업이 떠 있는 동안 다른 요청은 받지 않는다 (요청이 둘 겹치지 않게).
