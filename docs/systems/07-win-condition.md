# 07. 승리 조건

**최종 수정일**: 2026-09-17
**분류**: Core

---

## 1. 목적

게임이 끝나는 조건과 승자 판정 규칙을 정의한다.

---

## 2. 승리 조건 2가지

| # | 이름 | 조건 |
| --- | --- | --- |
| ① | **처치 승리** | 다른 모든 플레이어가 탈락하고 마지막 1인으로 생존 |
| ② | **찹츄 승리** | 손패 10장 도달 후 선언 → 다음 자신의 턴 시작까지 정확히 10장 유지 |

---

## 3. 처치 승리

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 판정 시점 | 모든 연쇄(체인) 처리가 끝난 뒤 — 단 01 · 02 는 "남은 1명이면 즉시"로 적혀 있어 충돌 (특히 게임 중 이탈로 1명이 남는 경우) | **미정** (2026-09-26 문서 재검토에서 발견, 결정 대기) |
| 조건 | 생존(`Alive`) 플레이어가 1명 | 확정 |
| 탈락자 카드 | 손패·설치 함정 모두 버림 더미로 소멸 | 확정 |
| 전원 최종 사망 | **무승부** | 확정 |

---

## 4. 찹츄 승리

### 4.1 선언

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 선언 조건 | 손패가 **정확히 10장** | 확정 |
| 선언 방식 | 소유자가 **찹츄 버튼을 직접 클릭** (자동 선언 아님) | 확정 |
| 선언 시점 | 손패 10장인 동안 언제든? — 재선언은 "자신의 턴에"(아래 4.2)라 첫 선언과 맞춰야 한다 | **미정** (턴 제한 여부 원문에 없음. `development-plan` 4-1 #4) |

### 4.2 유지

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 유지 조건 | 다음 자신의 턴 시작까지 **정확히 10장** 유지 | 확정 |
| 해제 | 10장이 아니게 되는 **순간 즉시 해제** | 확정 |
| 자동 재선언 | 없음 | 확정 |
| 재선언 | **자신의 턴에** 다시 선언 가능 | 확정 |

### 4.3 판정

> 선언 후 **자신의 다음 턴이 시작되는 순간** 찹츄 상태이면 승리.

* 생존 상태에서 자신의 턴이 시작될 때 손패가 정확히 10장이면 승리 조건 충족.
* 판정은 마스터가 한다.

## 5. 예외 — 다수 찹츄

| 상황 | 처리 | 구분 |
| --- | --- | --- |
| 여러 명이 동시에 찹츄 상태 | 가능하다. 서로 방해하는 것이 정상 플레이 | 확정 |
| 판정 | 가장 먼저 **자신의 다음 턴이 돌아온** 플레이어가 승리, 즉시 게임 종료 | 확정 |

---

## 6. 승리 조건 충돌

| 상황 | 처리 | 구분 |
| --- | --- | --- |
| 찹츄 승리와 처치 승리가 동시에 성립 가능 | 처리 중인 연쇄를 **끝낸 뒤 먼저 확정된 사건**을 적용 | 확정 |
| 연쇄 처리 중 승리 조건 충족 | 연쇄를 끝까지 처리한 후 판정 | 확정 |

---

## 7. 찹츄 상태를 조작하는 카드

| 카드 | 효과 |
| --- | --- |
| A02 | 찹츄 상태 플레이어 전원 HP - N |
| A20 | 첫 번째 대상의 찹츄 상태를 제거하고 두 번째 대상에게 부여 |
| A21 | 본인 패에서 무작위 N장 버린 후 본인의 찹츄 상태 제거 |
| C15 | 다른 플레이어가 본인에게 찹츄 상태를 부여할 때 무효화 |
| T04 | 찹츄 상태 플레이어 전원(본인 제외) 패에서 3장 강제 버림 |
| T16 | 본인에게 찹츄를 부여한 플레이어에게도 찹츄 상태 부여 |

> **찹츄 상태는 손패 10장에서 파생되는 값이 아니라, 별도로 부여·제거되는 상태다.** (A20이 이를 요구한다)
> 단, 손패가 10장이 아니게 되면 부여된 찹츄도 즉시 해제된다.

---

## 8. 상태 흐름

```
Normal ──(손패 10장 + 찹츄 버튼)──→ ChapChu
ChapChu ──(손패 ≠ 10장)──────────→ Normal (즉시 해제)
ChapChu ──(A20/A21 효과)────────→ Normal
Normal  ──(A20/T16 효과)────────→ ChapChu (손패 10장 아니면 즉시 해제)
ChapChu ──(자신의 턴 시작)───────→ 승리
```
