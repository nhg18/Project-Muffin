## 1. 목적

## 2. 승리 조건 2가지

| # | 이름 | 조건 |
| --- | --- | --- |
| ① | **처치 승리** | 다른 모든 플레이어가 탈락하고 마지막 1인으로 생존. 탈락 = 최종 사망 · 나가기 · 연결 끊김 뒤 강제 퇴장 — 전부 최종 사망 처리(`01-game-flow` 6절)라 어떻게 빠졌든 같은 승리다 (확정 2026-11-07) |
| ② | **찹츄 승리** | 손패가 정확히 10장이 되면 **자동으로** 찹츄 선언 → 선언한 사람의 턴이 시작되는 순간 손패가 정확히 10장이면 승리 (4절) |

## 3. 처치 승리

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 판정 시점 | 모든 연쇄(체인) 처리와 사망 대기가 끝난 뒤. 예: 마지막 상대를 처치했는데 그 상대의 T01(사망 시 생존자 전원 피해)로 나도 죽으면 무승부. 단 연쇄가 없는 때 이탈로 1명이 남으면 바로 판정 | 확정 (2026-10-30) |
| 조건 | 게임에 남은(나가지 않고 최종 사망하지 않은) 플레이어가 1명. 혼자 시작한 게임(개발용)은 판정하지 않는다 | 확정 / 제안 (혼자 시작) |
| 탈락자 카드 | 손패·설치 함정 모두 버림 더미로 소멸 | 확정 |
| 전원 최종 사망 | **무승부** | 확정 |

## 4. 찹츄 승리

### 4.1 선언

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 선언 조건 | 손패가 **정확히 10장**이 되는 순간 | 확정 |
| 선언 방식 | **자동** — 10장이 된 순간 방장이 그 사람을 찹츄 상태로 만든다. 플레이어 입력은 없다 (찹츄 버튼으로 선언하지 않는다) | 확정 (2026-11-14, 회의) — 「버튼 직접 클릭」 을 대체 |
| 선언 시점 | **언제든** — 내 턴 · 남의 턴, 10장이 된 이유(뽑기 · 카드 효과)를 가리지 않는다. 이미 찹츄 상태이면 다시 선언하지 않는다 | 확정 (2026-11-14, 회의) — 2026-11-07 「내 턴에만」 폐기 |
| 선언 대기 | **없다.** 내 턴에 뽑아서 10장이 되면 선언되고 턴은 보통대로 끝난다 (`03-turn` 4절) | 확정 (2026-11-14, 회의) — 2026-11-07 「5초 선언 대기」 폐기 |
| 여러 장이 한꺼번에 바뀔 때 | **효과 하나(또는 턴 뽑기 한 번)가 끝난 뒤의 장수**로만 본다 — 여러 장을 뽑는 도중에 지나친 10장은 선언이 아니다 (예: 9장에서 2장 뽑는 효과 → 11장, 선언 없음) | 확정 (2026-11-19, PM) |
| 사망 대기 중 | HP 0 · 사망 대기 중에는 10장이어도 **선언하지 않는다.** 대기 중 살아나면 그때 손패가 정확히 10장인지 보고 선언한다 (`06-health` 8절) | 확정 (2026-11-19, PM) |
| 선언 연출 | 선언된 순간 **바로** 전원 화면에 큰 이펙트 + 선언자 표시 유지 (`10-ui` 7절) | 확정 (2026-11-14, 회의) — 크기 · 길이는 시안에서 |

### 4.2 유지

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 유지 조건 | **없다** — 선언 뒤 손패가 10장이 아니게 돼도 찹츄 상태는 그대로다. 장수는 판정 때(4.3)만 본다 | 확정 (2026-11-14, 회의) — 「10장이 아니면 즉시 해제」 폐기 |
| 해제 (무효) | 찹츄 상태인 사람의 턴이 시작되는 순간 손패가 10장이 아니면 선언은 **무효** — 찹츄 상태가 풀린다 (4.3) | 확정 (2026-11-14, 회의) |
| 재선언 | 풀린 뒤 손패가 다시 정확히 10장이 되면 첫 선언과 같이 **자동으로** 선언된다 | 확정 (2026-11-14, 회의) |

### 4.3 판정

> 찹츄 상태인 사람의 **턴이 시작되는 순간** 손패가 정확히 10장이면 승리, 아니면 선언 무효 (4.2).

* 생존 상태 · 찹츄 상태에서 자신의 턴이 시작될 때 손패가 정확히 10장이면 승리 조건 충족. 스킵된 턴은 시작하지 않은 것이라 판정하지 않는다 (`03-turn` 7절).
* 판정 뒤의 일은 같은 규칙으로 풀린다 — 예: 9장으로 턴을 맞으면 무효, 그 턴에 뽑아 10장이 되면 재선언이고 승리는 그다음 자기 턴에 판정한다.
* 판정은 마스터가 한다.
* 「기다려」(1023 기다려!, `11-card-list` 1023) 가 걸려 있으면 판정만 건너뛴다 — 찹츄 상태는 그대로 두고, 그 사람의 다음 자기 턴에 다시 판정한다. 처치 승리는 막지 않는다. 건 사람의 「기다려」 는 그 사람의 실제 턴이 시작되기 전에 끝나므로 건 사람은 그 턴에 이길 수 있다 (2026-11-13).

## 7. 찹츄 상태를 조작하는 카드

| 카드 | 효과 |
| --- | --- |
| 찹츄 전원 피해 (A02) | 찹츄 상태 플레이어 전원 HP - N |
| 찹츄 옮기기 (A20) | 첫 번째 대상의 찹츄 상태를 제거하고 두 번째 대상에게 부여 |
| 자기 찹츄 해제 (A21) | 본인 패에서 무작위 N장 버린 후 본인의 찹츄 상태 제거 |
| 찹츄 부여 무효화 카운터 (C15) | 다른 플레이어가 본인에게 찹츄 상태를 부여할 때 무효화 |
| 찹츄 전원 3장 버림 함정 (T04) | 찹츄 상태 플레이어 전원(본인 제외) 패에서 3장 강제 버림 |
| 찹츄 되돌려 주기 함정 (T16) | 본인에게 찹츄를 부여한 플레이어에게도 찹츄 상태 부여 |

> **찹츄 상태는 손패 10장에서 파생되는 값이 아니라, 별도로 부여·제거되는 상태다.** (찹츄 옮기기 카드(A20)가 이를 요구한다)
> 부여된 찹츄도 선언한 찹츄와 같이 그 사람의 턴이 시작될 때 판정한다 (4.3, 2026-11-14).
