## 1. 원칙

1. **UI는 판정하지 않는다.** 마스터가 브로드캐스트한 결과만 표시한다.
2. UI는 `GameEvents` 또는 Photon 콜백을 **구독**해서 갱신한다. 매 프레임 폴링하지 않는다.
3. 확정 전 값(예: 계산 중인 HP)을 최종 수치처럼 표시하지 않는다.
4. 연출(트윈·확대·이동)은 로컬 자유. 규칙에 영향을 주지 않는다.

#### 3D 층 구현 (2026-11-06)

3D 층은 월드 공간의 메시(Quad)와 TMP 3D 글자다. 2D 층은 Overlay 캔버스라 항상 3D 층 위에 그려지고, 배경은 3D 층 뒤의 카메라 캔버스(거리 50)에 둔다. 포인터는 카메라의 `PhysicsRaycaster` 가 콜라이더로 맞춘다 (내 카드는 아래 「손패 층」의 손패 카메라가). 좌석 · 상대 손패 · 이름표는 2D 층(HUD) — HUD v2 시안과 같다. **이전에 3D 였던 것(카드 · 덱 · 손패 · 내는 자리 · 버림)은 계속 3D** (2026-11-07 결정).

### 사용 요청

* 대상을 고르는 카드(`OneOther · TwoOthers`)를 **상대 위에 놓으면** 그 상대를 대상으로 바로 요청한다. 테이블 · 기준선 위에 놓으면 대상 고르기(6절)로 간다.
* 대상이 자동(`None · Self · AllOthers · Everyone`)이면 빈 대상으로 바로 요청한다.
* 로컬 조건은 보지 않는다 — 방장이 거절하면 토스트 (8-2).
* 요청한 카드는 **마스터 승인(`OnCardUsed`) 뒤에만** 손패에서 지운다 (2026-10-10). 승인 전에는 손패 자리로 돌아가 있고, 거절되면 그대로다. 승인 대기 중 다른 카드를 내도 UI 는 막지 않는다 — 서버가 거절한다.
* **잠김**: 내 카드 연출 중 · 대상 고르기 중 · 체인 처리 중(반응 시간이 끝난 뒤)에는 손패 입력을 받지 않는다. 반응 시간에는 카운터를 내야 하므로 잠그지 않는다.

### 5-1. 카드 연출 단계 (2026-11-04 확정 · 2026-11-11 4 단계로)

카드 하나가 사용(발동)될 때 연출은 아래 순서로 진행된다. 1 · 2 · 4 는 모든 카드가 공통으로 쓰고, 3 은 카드마다 다르다 — **그 이펙트가 있는 카드만** 재생하고 없으면 건너뛴다. 4 단계에 카드만의 연출을 더할 수 있는 것은 **「개판」 등급 카드뿐**이다 (아래 「4 단계 공통 연출」, 2026-11-17 PM). 연출은 로컬이며 판정에 영향을 주지 않는다 (1절 #4).

**반응 시간(카운터 · 함정 대기)은 2 단계 바로 뒤에 열린다. 3 · 4 단계는 체인이 끝난 뒤 효과가 적용되는 카드만 재생하고, 카운터로 막힌(무효화 · 불발) 카드는 재생하지 않는다** — 확정 (2026-11-08, PM).

**카드 고유 이펙트는 3 단계(능력 발동 연출) 한 곳에서만 재생한다.** 반응 시간 앞에 따로 두었던 「카드 짧은 연출 이펙트」 단계는 없앴고, 그 내용은 능력 발동 연출에 합쳤다 — 확정 (2026-11-11, PM).

```
  └ 무효화 · 불발된 카드: 도장(5절) → 버림 더미 (3 · 4 없음)
```

**카드 연출 소리** (2026-11-28) — 3 단계가 있는 카드와 지옥참마도의 4 단계는 「카드 이펙트 v2」 시안의 소리를 그대로 쓴다. 시안이 장면마다 코드로 합성하던 소리를 장면 시작부터 끝까지 한 파일로 녹음해 두고, 연출 그림과 같이 불러와 **장면 시계가 0 이 되는 순간** 튼다 — 그래서 시안과 같은 시각에 울린다. 불러오는 동안 장면이 먼저 흘렀으면 그만큼 건너뛰고 튼다. 효과음 스위치를 따른다. 대소동(1012)은 시안의 배경 관현악까지 한 파일이다. 파일끼리 음량은 맞춰 두었다(순간 최대 −17 LUFS, 띠 컷인 1002 · 1016 · 1020 은 작은 팝 · 삐 소리라 −21). 연출 길이 · 장면을 시안과 다르게 고친 카드(1005 의 지운 글자 등)도 소리는 시안 그대로다.

**배경음** (2026-11-28, PM) — 게임 화면은 「카드 이펙트 v2」 시안의 배경음을 쓴다. 시안이 코드로 합성하던 8마디 루프(C · Am · F · G 두 번, 128 BPM)를 한 바퀴(15초) 녹음한 파일 하나를 이음매 없이 반복한다. 게임 화면에 들어오면 1.2초에 걸쳐 커지고(시안과 같다), 나가면 0.5초에 줄여 멈춘다. 다음 판은 처음부터. 배경음 스위치를 따른다. 방 · 결과 화면은 틀지 않는다. 타이틀 · 로비 곡과 같은 음량 값을 쓰고, 파일은 로비 곡보다 3dB 작게 맞췄다(−21 LUFS) — 카드 연출 소리(−17)가 묻히지 않게. 시안의 영역 전개 음악(HORIZON)은 쓰지 않는다.

#### 카운터 · 함정이 끼어든 경우 (체인)

* **2 단계가 끝난 뒤**(반응 시간), 다른 플레이어가 **선택적으로** 카운터 카드나 함정 카드를 끼워 넣을 수 있다 (04-card 6 · 7절의 반응 시간).
* 끼어든 카운터 · 함정 카드도 **1 · 2 단계를 똑같이** 연출한다. 그 뒤에 다시 반응 시간이 열리고 카운터가 끼어들 수 있다.
* 3 · 4 단계는 체인 중간에 재생하지 않는다. 체인이 끝나면 최종적으로 **효과가 적용되는 카드 한 장**만 남고, 그 카드의 3 · 4 단계를 그때 재생한다.
* 무효화된 카드는 3 · 4 단계가 없다. 무효화 자체의 연출은 X 도장 0.3초 + 회색조 (5절 표, 확정 2026-11-07). 체인 안에서 어느 카드가 살았는지는 카드 배치로 보인다 (2-1 「카드 연출 자리」).

예 — 행동 카드 A → 카운터 B → 카운터 C 순서로 체인이 이어진 경우

```
A: 1 → 2 → 반응 시간
B: 1 → 2 → 반응 시간    (A 를 무효화)
C: 1 → 2 → 반응 시간    (B 를 무효화) → 아무도 안 냄
체인 종료 → B 무효(도장) → A 효과 적용 → A 의 3 → 4 단계 재생
(3 단계는 그 이펙트가 있는 카드만)
```

* 옮기지 않은 것: v3 「도감 · 수치」(다음 판의 카드 장수 · 효과 값 바꾸기 — 카드 원본은 `cards.json` 이고 원격 패치가 없어 빌드 밖에서 바꿀 길이 없다, `26-card-data`) · v2 「단계 시간」 조절 (연출 시간이 카드별 연출 에셋 · 컴포넌트 값에 흩어져 있다). 필요하면 정한다.
