# 10. 인게임 UI

**최종 수정일**: 2026-09-17
**분류**: Core

---

> 이 문서는 인게임 UI만 다룬다. 타이틀 화면은 [`12-title-ui.md`](12-title-ui.md).

## 1. 원칙

1. **UI는 판정하지 않는다.** 마스터가 브로드캐스트한 결과만 표시한다.
2. UI는 `GameEvents` 또는 Photon 콜백을 **구독**해서 갱신한다. 매 프레임 폴링하지 않는다.
3. 확정 전 값(예: 계산 중인 HP)을 최종 수치처럼 표시하지 않는다.
4. 연출(트윈·확대·이동)은 로컬 자유. 규칙에 영향을 주지 않는다.

## 3. 좌석 UI (`PlayerSeat`)

| 요소 | 표시 조건 | 표시 내용 | 갱신 시점 |
| --- | --- | --- | --- |
| 닉네임 | 항상 | 닉네임 | 입장 시 1회 |
| HP 텍스트 | 항상 | `현재 HP / 100` | HP 변경 |
| HP 게이지 | 항상 | 비율 바 | HP 변경 |
| HP 경고색 | HP 1~20 | 경고색 | 위험 상태 진입/해제 |
| 손패 장수 | 항상 | 숫자 | handCount 변경 |
| 함정 슬롯 | 항상 | 3칸, 설치된 칸은 뒷면 카드 | trapCount 변경 |
| 턴 표시 | 해당 플레이어 턴 | 초록색 외곽선 | 턴 변경 |
| 턴 타이머 | 해당 플레이어 턴 | 프로필 위 남은 초 (**제안**) | 매 프레임(로컬 계산) |
| 사망 대기 | `DeathPending` | "사망 대기" + 남은 대응 시간 | 상태 변경 |
| 최종 사망 | `Dead` | 영역 비활성 + "사망" | 상태 변경 |
| 찹츄 표시 | `isChapChu` | 찹츄 아이콘 | 상태 변경 |
| 대상 선택 강조 | 대상 선택 대기 중 + 선택 가능 | 하이라이트 | 선택 시작/종료 |

## 4. 손패 UI

| 요소 | 표시 조건 | 동작 |
| --- | --- | --- |
| 손패 배치 | 항상 | 스플라인 부채꼴. 10장 초과 시 간격 축소 |
| HandMode ON | 손패 카드 탭 | 손패 전체를 위로 올림 |
| HandMode OFF | 손패 외 영역 탭 | 손패를 아래로 내림 |
| 카드 호버 | HandMode + 포인터 진입 | 카드 확대 + 최상단 정렬 |
| 카드 드래그 | HandMode + 드래그 | 카드가 포인터를 따라감 |
| 드롭 성공 | 드롭 영역 위에서 놓음 + 로컬 조건 통과 | 카드 사용 요청 |
| 드롭 실패 | 그 외 | 원위치 복귀 |

> ⚠ **현재 카드를 사용해도 손패 뷰에서 제거되지 않는다.** 마스터 승인 후 제거하는 처리가 필요하다.

### 상대 손패

| 요소 | 표시 |
| --- | --- |
| 카드 | 뒷면만 |
| 장수 | handCount와 동일하게 유지 |

## 5. 카드 처리 UI

| 요소 | 표시 조건 | 표시 내용 |
| --- | --- | --- |
| 현재 처리 카드 | 체인에 카드 존재 | 화면 중앙에 카드 앞면 |
| 체인 표시 | 체인이 2장 이상 | 쌓인 순서대로 표시 (**미정** — 표현 방식) |
| 반응 타이머 | 반응 시간 진행 중 | 남은 초 (전원 동일) |
| 카운터 사용 안내 | 반응 가능한 카드 보유 | **미정** — 어떻게 알리고 어떻게 고르는가 |
| 무효화 연출 | 카드가 무효화됨 | **미정** |

## 6. 대상 선택 UI

| 단계 | 동작 | 구분 |
| --- | --- | --- |
| 진입 | 대상 지정이 필요한 카드를 드롭하면 선택 모드 시작 | 확정 |
| 선택 | 대상 플레이어 좌석을 탭 | 확정 |
| 취소 | 우클릭 / 취소 버튼 | 확정(우클릭 구현됨) / **미정**(모바일 입력) |
| 제한 시간 | 5초 (코드값) | **제안** — 기획에 값 없음 |
| 타임아웃 | 카드 사용 취소, 손패 복귀 | 확정 |

> ⚠ 현재 취소 입력이 **마우스 우클릭**이다. 모바일 타겟이므로 대체 입력이 필요하다.

## 8. 팝업 / 토스트

| 종류 | 용도 | 구현 |
| --- | --- | --- |
| `WarningPopup` | 경고·에러 | 구현됨 |
| `InputPopup` | 입력(방 코드 등) | 구현됨 |
| `MessageToast` | 짧은 알림 | 구현됨 — `PopupManager.ShowToast("문구")` |
| `LoadingPopup` | 대기 | 구현됨 (사용처 없음 — 방 참가 대기에 쓸 예정, PR5) |
| 카드 거절 사유 | 마스터가 요청을 거절했을 때 | **미구현** (B2-6, `MessageToast` 사용) |

### 8-1. 토스트 규칙

| 항목 | 값 | 구분 |
| --- | --- | --- |
| 표시 시간 | 3초 후 스스로 닫힘 | 확정 |
| 누르면 | 즉시 닫힘 | 확정 |
| 위치 | 화면 아래 가운데, 아래에서 48 위 | 제안 (디자인 기준 없음) |
| 동시에 여러 개 | 쌓여서 각자 닫힘 | 현행 |
| 씬 전환 | 모든 팝업 · 토스트를 닫는다 | 확정 |

호출: `PopupManager.ShowToast("문구")`. 모달은 `OpenModal<T>()`, 닫기는 `popup.Close()` (API 전체는 `worklog.md` 2026-09-24 팝업 항목).

## 9. 입력 정리

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| 손패 카드 탭 | HandMode ON | 항상 |
| 빈 영역 탭 | HandMode OFF | HandMode ON일 때 |
| 카드 드래그 → 드롭 영역 | 카드 사용 요청 | HandMode + 조건 충족 |
| 플레이어 좌석 탭 | 대상 선택 | 대상 선택 모드 |
| 우클릭 | 대상 선택 취소 | 대상 선택 모드 (**모바일 대체 필요**) |
| 덱 탭 | 드로우 요청 | 자신의 턴 + 메인 행동 미사용 |
| 찹츄 버튼 | 찹츄 선언 | 손패 10장 |
| 턴 종료 버튼 | 턴 종료 | **디버그 전용** |

## 10. 현재 구현 상태

| 항목 | 상태 |
| --- | --- |
| 손패 부채꼴 배치 / 호버 / 드래그 | 구현됨 (`PlayerHandView`, `CardView`) |
| 상대 손패 뒷면 표시 | 구현됨 (`OtherPlayerHandView`) |
| 좌석 닉네임 / 턴 외곽선 | 구현됨 (`PlayerSeat`) |
| 좌석 HP / 손패 장수 | 함수만 존재, **호출되지 않음** |
| 함정 슬롯 UI | **미구현** |
| 반응 타이머 UI | **미구현** |
| 체인 표시 | 중앙에 카드 인스턴스를 띄우고 일정 시간 후 `Destroy` (임시) |
| 대상 선택 | 구현됨 (`TargetSelectionManager`, `PlayerSeat.OnPointerClick`) |
| 찹츄 버튼 | **미구현** |
| 결과 화면 | **미구현** |
| 팝업 시스템 | 구현됨 (단, 토스트는 예외 — 위 `ToastPopup` 행 참고) |
