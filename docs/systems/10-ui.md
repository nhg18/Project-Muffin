# 10. 인게임 UI

**최종 수정일**: 2026-11-06
**분류**: Core

---

> 이 문서는 인게임 UI만 다룬다. 타이틀 화면은 [`12-title-ui.md`](12-title-ui.md).

## 1. 원칙

1. **UI는 판정하지 않는다.** 마스터가 브로드캐스트한 결과만 표시한다.
2. UI는 `GameEvents` 또는 Photon 콜백을 **구독**해서 갱신한다. 매 프레임 폴링하지 않는다.
3. 확정 전 값(예: 계산 중인 HP)을 최종 수치처럼 표시하지 않는다.
4. 연출(트윈·확대·이동)은 로컬 자유. 규칙에 영향을 주지 않는다.

### 2-1. 주요 수치 (HTML 시안 → 캔버스)

**시안**: 아티팩트 「프로토타입」 https://claude.ai/artifact/HMPHz12ufhpGGevAfS11s6 — **기준: 2026-11-06 게시본 `1793928535-9e82`** (확정 2026-11-06). 아티팩트를 고쳐도 **이 절의 버전 ID 를 바꾸기 전까지는 이 게시본이 기준**이다. 갱신했다면 버전 ID 와 바뀐 수치를 여기에 먼저 적는다. 캔버스는 [`15-screen.md`](15-screen.md) 3절 — 1920 × 1080 · Expand · 가로 고정. 가장자리 UI 는 `SafeArea` 아래, 중앙 묶음(덱 · 버림 · 오버레이)과 배경은 밖.

시안은 **2.5D** 다 ([`00-overview.md`](00-overview.md) 1절 엔진). 원근 시점에서 기울어진 테이블 위에 카드 · 이름표를 놓고, HUD 는 화면에 2D 로 덮는다.

| 층 | 들어가는 것 |
| --- | --- |
| 3D (원근 · 기울인 테이블) | 테이블 · 카드(앞뒷면 두 장, 뒤집기 = Y 축 180°) · 손패 · 덱 · 버림 더미 · 체인 · 함정 슬롯 · 좌석 이름표(테이블 위에 세운 판) · 카드 이동(높이를 올린 아치) |
| 2D (화면 고정) | 상단 바 · 내 정보 판 · 선택 안내 · 체인 목록 · 기록 · 알림 · 연출 레이어(숫자 · 도장 · 배너 · 컷인) · 배경 |

카드 한 장은 두께 없는 평면이다. 덱 두께는 겹친 그림자로 흉내 낸다. 기울기 · 시점 · 높이 같은 수치는 아래 「옛 시안 수치」를 다시 뽑을 때 함께 정한다.

> **옛 시안 수치 — 미정 (2026-11-06)**: 아래 「색 · 글꼴」부터 「시안에 있지만 넣지 않는 것」까지는 옛 시안(아티팩트 「인게임 화면 UI」 2026-09-28 판, 2D 픽셀 풍 — 사본 `docs/mockups/ingame.html` 은 지웠고 git 기록 `2e29dc97` 에 있다)에서 뽑은 값이다. 새 시안에서 다시 뽑기 전까지 **미정** — 이 값으로 새로 만들지 않는다. 다시 뽑을 때 CSS px → 캔버스 배율(아래 × 2)도 다시 정한다.

> 시안의 CSS px 는 **× 2** 가 캔버스 px 다 (2026-11-02 결정). `vh` · `vw` 는 1920 × 1080 기준으로 환산한 뒤 `clamp` 를 적용한다. 아래 값은 전부 캔버스 좌표.

### 5-1. 카드 연출 단계 (2026-11-04 확정)

카드 하나가 사용(발동)될 때 연출은 아래 순서로 진행된다. 1 · 2 · 4 는 모든 카드가 공통으로 쓰고, 3 만 카드마다 다르다. 연출은 로컬이며 판정에 영향을 주지 않는다 (1절 #4).

| # | 단계 | 범위 | 연출 |
| --- | --- | --- | --- |
| 1 | 카드 내는 중 | 공통 | 손패(함정은 함정 슬롯)에서 나온 카드가 테이블 위로 올라간다 |
| 2 | 테이블에 올려짐 | 공통 | 테이블에 놓인 카드가 확대된다. 모든 플레이어 화면에서 카드의 제목 · 이미지 · 설명을 크게 볼 수 있는 구간 |
| 3 | 카드 이펙트 | 카드별 | 카드마다 고유한 이펙트 (카드별 정의는 노션 「카드 이펙트」 하위 페이지) |
| 4 | 후처리 이펙트 | 공통 | 효과가 적용되는 대상에게 재생. 피해가 들어가는 순간의 숫자 터짐 · 파편 · 화면 흔들림 · HP 감소 (06-health 「결과 수신 후 재생」) |

4 단계가 끝나면 카드는 버림 더미로 날아간다.

3 단계 카드 이펙트의 그림은 **그 카드의 연출을 재생할 때 불러오고, 끝나면 내린다.** 게임 화면에 미리 올려 두지 않는다 — 카드 하나의 이펙트 그림이 모바일에서 십수 MB 다 (「지옥참마도」 약 18MB, 2026-11-05 확정).

#### 카운터 · 함정이 끼어든 경우 (체인)

* 3 단계가 끝난 뒤, 다른 플레이어가 **선택적으로** 카운터 카드나 함정 카드를 끼워 넣을 수 있다 (04-card 6 · 7절의 반응 시간).
* 끼어든 카운터 · 함정 카드도 **1 · 2 · 3 단계를 똑같이** 연출한다. 그 뒤에 다시 카운터가 끼어들 수 있다.
* 4 단계는 체인 중간에 재생하지 않는다. 체인이 끝나면 최종적으로 **효과가 적용되는 카드 한 장**만 남고, 그 카드의 4 단계를 그때 재생한다.
* 무효화된 카드는 4 단계가 없다. 무효화 자체의 연출은 **미정** (5절 표 · 11절 #5).

예 — 행동 카드 A → 카운터 B → 카운터 C 순서로 체인이 이어진 경우

```
A: 1 → 2 → 3
B: 1 → 2 → 3        (A 를 무효화)
C: 1 → 2 → 3        (B 를 무효화)
체인 종료 → B 무효 → A 효과 적용 → A 의 4 단계 재생
```

> 현재 `CardFxTestScene` 값: 1 단계 0.46초, 4 단계 뒤 0.9초 대기 후 버림 더미로 0.38초. 2 단계(확대 구간)는 아직 없다. 유니티와 아티팩트 시안이 다르면 유니티가 기준 (2026-11-03).

| 타임아웃 | 카드 사용 취소, 손패 복귀 | 확정 |

> ⚠ 현재 취소 입력이 **마우스 우클릭**이다. 모바일 타겟이므로 대체 입력이 필요하다.

> 차단 범위는 **드롭 → 대상 확정(또는 취소·타임아웃)** 까지다. 마스터의 5초 반응 시간에는 카운터 카드를 내야 하므로 잠그지 않는다.
