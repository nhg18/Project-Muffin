## 3. 메인 행동 (확정)

자신의 턴에 **둘 중 하나만** 선택할 수 있고, 선택하면 턴이 종료된다.

| 선택 | 결과 |
| --- | --- |
| 카드 드로우 — **2장** (손패가 정확히 9장이면 **1장** — 딱 10장이 되게) (`05-deck` 4절, 2026-11-11) | 드로우 완료 후 턴 종료. 드로우로 손패가 정확히 10장이 되면 찹츄가 자동 선언되고 턴은 그대로 끝난다 (`07` 4.1). **읽는 시간 3초** — 사람이 직접 뽑아 카드를 받았으면 뽑은 뒤 3초가 지나야 다음 턴이 시작된다 (뽑은 카드를 읽게, PM 2026-11-28 플레이 테스트). 봇 · 시간 초과 자동 뽑기(4절)는 기다리지 않는다. 함정 · 사망 정리가 더 길면 그쪽을 기다린다 |
| 행동 카드 1장 사용 | 카드 처리(반응 시간 포함) 완료 후 턴 종료 |

**함정 설치는 메인 행동이 아니다.** 빈 슬롯이 있으면 자신의 턴에 몇 장이든 설치할 수 있고, 설치 후에도 메인 행동을 할 수 있다.

### 시간 초과 자동 행동 (확정 2026-11-19, PM)

| 순서 | 처리 |
| --- | --- |
| 1 | 방장이 그 사람 대신 **뽑는다.** 카드는 내지 않는다 — 자리에 없는 사람의 무작위 카드가 남의 판을 흔들지 않게 (PM 2026-11-19) |
| 2 | 뽑는 장수는 자동 뽑기로 **10장이 되지 않게** 맞춘다 — 손패 **7장 이하 2장 · 8장 1장 · 9장 0장**(뽑지 않고 턴만 넘어간다) · **10장 이상 2장**. 자리에 없는 사람이 자동 뽑기로 찹츄를 선언해 이기지 않게 (PM 2026-11-19). 직접 누른 뽑기는 그대로다 (9장이면 1장 — 3절) |
| 3 | 그 밖에는 보통 뽑기와 같다 — 빈 덱이면 못 뽑은 장마다 빈 덱 피해 (`05-deck` 5절), 끝나면 턴 종료. 0장인 턴은 뽑기를 시도하지 않으므로 빈 덱 피해도 없다 |
| 4 | 함정 설치는 하지 않는다. (고르기 효과는 이제 없다 — 1019 는 무작위, 사용자 2026-11-28) |

* 연결이 끊긴 사람의 턴도 같다 — 다만 **5초**에 시간 초과 (10절).
* 봇은 시간 초과가 없으므로(`18-bot` 11절) 자동 행동을 받지 않는다 — 봇이 의도적으로 턴을 흘리는 경우(요청 상한 · 「기다림」)의 처리는 `18-bot` 이 정한다.

* 연속 시간 초과 횟수는 **방장**이 플레이어마다 센다. **시간 초과가 아닌 턴 종료**(뽑기 · 카드 사용)가 한 번 있으면 0 으로 돌아간다. 0장을 뽑은 시간 초과도 센다. 스킵된 턴은 시작하지 않은 것(7절)이라 세지 않는다. 연결 끊김으로 넘어간 턴은 시간 초과로 센다 (10절). 3번째에는 자동 행동 없이 바로 퇴장이다. (확정 2026-11-07 — N = 3 · 세는 방법 / 2026-11-19 — 바로 퇴장)

## 6. 턴 순서 결정 (확정 + 제안)

1. 게임 시작 시 마스터가 참가자 목록을 **무작위로 섞어** 턴 순서 배열을 만든다. (확정: 무작위)
2. 이 배열을 모든 클라이언트에 알린다 — 방 속성 `turnOrder` (int[], `09-network` 6절). 게임 시작 · 대소동 새 판(1012)에 쓴다. 화면의 턴 순서 줄과 「다음 사람」 을 쓰는 연출은 좌석 순서가 아니라 이 순서를 따른다. (2026-11-28 — 화면이 좌석 순으로 그려 실제 턴과 어긋나던 것을 고침)
3. 이후 턴 이동은 이 배열에서 **진행 방향**으로 다음 **생존** 플레이어를 찾는다. (확정)
4. **진행 방향**은 정방향(배열 순) · 역방향 둘 중 하나로, 게임 시작은 정방향이다. 방향은 마스터가 들고 한 판 동안 유지한다 — 반전 카드가 바꾸고, 다시 반전하면 정방향으로 돌아온다. 다른 카드의 「다음 플레이어」(손패 무작위 N장을 다음 플레이어에게 넘기는 카드(A10) 등)도 이 방향을 따른다. (확정 2026-11-07)

## 7. 턴 이동 규칙

| 상황 | 처리 | 구분 |
| --- | --- | --- |
| 정상 종료 | 다음 생존 플레이어로 이동 | 확정 |
| 현재 턴 플레이어가 사망 확정 | 해당 턴 종료 후 다음 생존 플레이어로 | 확정 |
| 다른 플레이어 사망 | 처리 후 기존 턴 플레이어 진행으로 복귀 | 확정 |
| 최종 사망 플레이어 | 턴 순서에서 제외 — 사망 정리에서 최종 사망이 정해진 때 (`06` 8절) | 확정 (2026-10-30) |
| 현재 턴 플레이어가 퇴장 | 다음 플레이어에게 턴 이동 | 확정 |
| 턴 시작 — 찹츄 판정 | 찹츄 상태인 사람의 턴이 시작되는 순간 손패가 정확히 10장이면 승리, 아니면 선언 무효 (`07-win-condition` 4.3). 턴 시작의 다른 처리보다 먼저 본다 | 확정 (2026-11-14, 회의) |
| 턴 스킵 효과 — 대상의 다음 턴을 건너뛰게 하는 행동 카드(A01) · 나를 노린 행동 카드를 취소하고 시전자의 다음 턴을 건너뛰게 하는 함정(T05) | 해당 플레이어에게 "다음 턴 스킵"을 **설정**. 겹쳐 받아도 쌓이지 않고 1회만 건너뜀. 스킵된 턴은 시작하지 않은 것으로 본다 — 찹츄 승리 판정 · 턴 시작 드로우가 없다. 스킵 직후 「턴 스킵된 후」 함정 시간 (`04` 6절). **스킵이 설정되면 전원에게 보인다** — 그 사람의 효과 HUD 에 스킵 표시를 달고, 스킵된 턴이 지나가면 뗀다. 설정될 때 기록 한 줄 (`10-ui` 6절 효과 HUD) | 확정 (2026-10-30) / 확정 (스킵된 턴 처리, 2026-11-06) / 확정 (표시, 2026-11-22 PM) |
| 턴 시작 추가 드로우 — 턴이 스킵된 뒤 다음 실제 턴에 N장 더 뽑는 함정(T15) | 「다음 실제 턴 시작 시 N장」 — 스킵되지 않은 다음 내 턴이 시작될 때 뽑는다. 메인 행동이 아니다 | 확정 (2026-11-06) |
| 턴 시작 상태 — 1067 GOAT 세기 · 1008 영역전개의 빼앗기 + 피해 | 실제 턴이 시작된 직후, 순서: 찹츄 판정 → 턴 시작(추가 드로우) → **GOAT 세기 → 영역** → 사망 정리 → 함정 줄. 스킵된 턴에는 없다. 카드를 낸 것이 아니라 반응 시간이 없고, 영역 처리를 보이는 1.2초 동안 그 턴의 시간은 멈춘다 (`11-card-list` 1008 · 1067) | 확정 (2026-11-28) |
| 턴이 끝날 때의 처리 — 1012 대소동 피폭 · 1021 개판 오분전 세기 | 순서: 피폭 → 개판 세기 (프로토타입 v2). 피폭은 실제 턴이 끝날 때마다(다음 턴으로 넘어가기 전) 전원 kⁿ — 스킵된 턴은 피해 없음. 개판은 **스킵된 턴도 1턴으로 센다**. 피폭의 사망 대기 · 함정 시간, 개판 판정(공개 10.92초 = 판정 팻말 4.17 + 처형 장면 6.75 → HP 0 → 사망 대기)이 생기면 그것을 마친 뒤 다음 턴 — 그동안 턴 시간이 멈춘다 (`11-card-list` 1012 · 1021) | 확정 (2026-11-13, 사용자) |
| 「다음 턴」 까지 가는 상태 — 다음 턴 행동 카드 금지(1007 짖기) · 내 다음 차례까지 찹츄 승리 없음(1023 기다려!) | 「다음 턴」 은 **실제로 오는** 다음 턴이다. 그 턴이 턴 스킵으로 건너뛰어지면 상태는 남아 그다음 실제 턴에 적용 · 종료된다 (스킵된 턴은 시작하지 않은 것 — 위 줄). 행동 금지는 실제 턴이 시작될 때 걸리고 그 턴이 끝날 때 풀린다. 기다려는 건 사람의 실제 턴이 **시작되기 전에** 끝난다 | 확정 (2026-11-13, 사용자) |
| 턴 방향 반전 — 진행 방향을 뒤집는 행동 카드(A07) | 진행 방향을 반대로 (6절 #4). 반전한 뒤 턴 종료 시 **반대 방향의 다음 생존 플레이어**로 간다. 생존자가 **2명**이면 반전해도 다음 사람이 같아 카드가 헛되므로, 이때는 **다음 플레이어를 건너뛰어 내 턴이 다시 온다** (Uno 의 2인 리버스와 같다) | 확정 (2026-11-07) |
| 턴 가로채기 — 행동 카드를 막고 바로 내 턴을 얻는 카운터(2013 새치기) | 그 체인의 처리(함정 · 사망 대기 포함, `04` 9.2)가 끝나면 막힌 카드를 쓴 사람의 턴이 끝나고, 다음 턴은 진행 방향의 다음 사람이 아니라 **새치기를 낸 사람**이다. 사이 사람들의 턴은 시작하지 않는다. 그 뒤 순서는 진행 방향으로 **새치기를 낸 사람의 다음 사람부터** — 원래 순서로 돌아가지 않는다. 새치기 턴은 보통 턴과 같아 찹츄 판정 · 행동 금지 · 기다려! 종료 등 「내 턴」 판정이 모두 적용된다. 새치기를 낸 사람에게 턴 스킵이 걸려 있으면 그 턴이 건너뛰어지고(스킵은 쓰인다) 그 다음 사람으로 간다. 새치기가 무효되면 아무 일도 없다. **건너뛴 사람들**의 턴은 시작하지 않은 것이다 — 그들의 「다음 턴」 상태(턴 스킵 · 행동 금지 · 턴 시작 추가 드로우)는 쓰이지 않고 남아 다음 실제 턴에 적용되고, 1021 개판도 그 턴들을 세지 않는다 (실제로 진행된 턴만 — 바퀴는 지금처럼 생존자 수만큼의 턴). **막힌 사람의 턴 끝 처리**(피폭 → 개판 세기)는 보통대로 한 뒤 새치기 턴이 온다. 턴 스킵으로 건너뛰어진 새치기 턴은 다른 스킵된 턴과 같다 (개판 1턴 · 「턴 스킵된 후」 함정). **새치기를 낸 사람이 턴이 오기 전에 빠지면**(나감 · 최종 사망) 그 사람 자리의 다음 사람에게 간다 | 확정 (2026-11-20 A안, `11-card-list` 2013) / 확정 (건너뛴 사람 · 개판 · 빠질 때, 사용자 2026-11-24) |

> 방향 개념은 방향 반전 카드(A07) 와 손패 무작위 N장을 다음 플레이어에게 넘기는 카드(A10) 가 요구해서 넣었다 (2026-11-07). 반전은 3 ~ 4인에서 「내 다음에 공격할 사람」을 바꾸는 카드이고, 2인에서는 연속 턴 카드가 된다.
