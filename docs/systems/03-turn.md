# 03. 턴 시스템

**최종 수정일**: 2026-11-07
**분류**: Core

---

## 1. 목적

플레이어가 자신의 턴에 할 수 있는 행동과 턴 전환 규칙을 정의한다.

## 3. 메인 행동 (확정)

자신의 턴에 **둘 중 하나만** 선택할 수 있고, 선택하면 턴이 종료된다.

| 선택 | 결과 |
| --- | --- |
| 카드 1장 드로우 | 드로우 완료 후 턴 종료. 단, 드로우로 손패가 정확히 10장이 되면 5초 「선언 대기」 뒤 종료 (4절) |
| 행동 카드 1장 사용 | 카드 처리(반응 5초 포함) 완료 후 턴 종료 |

**함정 설치는 메인 행동이 아니다.** 빈 슬롯이 있으면 자신의 턴에 몇 장이든 설치할 수 있고, 설치 후에도 메인 행동을 할 수 있다.

## 4. 상태 흐름

| 현재 상태 | 조건 | 다음 상태 | 결과 | 구분 |
| --- | --- | --- | --- | --- |
| `WaitingTurn` | 자신의 차례 도래 | `MyTurn` | 제한 시간 카운트 시작 | 확정 |
| `MyTurn` | 카드 1장 드로우 선택 (드로우 뒤 손패 ≠ 10장) | `TurnEnd` | 드로우 완료 후 턴 종료 | 확정 |
| `MyTurn` | 카드 1장 드로우 선택 — 드로우 뒤 손패가 **정확히 10장** | `DeclareWait` (선언 대기) | 턴이 바로 끝나지 않고 **5초** 선언 대기가 열린다. 시간 측정 · 판정은 **방장**. 대기 중 다른 입력(카드 사용 · 다시 뽑기 · 함정 설치)은 받지 않는다 — 찹츄 버튼만. 턴 제한 시간 20초와 **별개 창**이다 (20초가 남았어도 5초만) | 확정 (2026-11-07, PM) |
| `DeclareWait` | 찹츄 선언이 방장에게 승인됨 | `TurnEnd` | 승인된 순간 턴 종료 — 5초를 기다리지 않는다 | 확정 (2026-11-07, PM) |
| `DeclareWait` | 5초 경과 · 선언 없음 | `TurnEnd` | 턴 종료. **시간 초과가 아니다** — 연속 시간 초과 횟수는 0 으로 | 확정 (2026-11-07, PM) |
| `MyTurn` | 행동 카드 1장 사용 | `Resolving` → `TurnEnd` | 체인 처리 완료 후 턴 종료 (불발돼도 종료) | 확정 |
| `Resolving` | — | — | 턴 제한 시간은 멈춘다 (체인이 20초를 넘겨도 턴을 넘기지 않는다). 체인 처리 뒤 후처리 시간(`04-card.md` 8절)이 지나면 `TurnEnd` | 확정 (2026-11-06) |
| 누군가 사망 대기 | — | — | 게임이 멈춘다 — 사망 대기가 끝나고(`06-health.md` 8절) 이어서 `TurnEnd` | 확정 (2026-11-06) |
| `MyTurn` (메인 행동 전) | 누군가 함정을 발동 · 함정 시간 · 사망 대기 | 멈춤 → `MyTurn` | 턴 제한 시간이 멈췄다가 **남은 시간으로 이어진다** (재개 시각을 다시 알린다) | 확정 (2026-11-06) |
| `MyTurn` | 내 턴 중 **드로우가 아닌 이유**(턴 시작 추가 드로우 · 카드 효과)로 손패가 정확히 10장이 됨 | 그 처리(체인 · 함정 확인)가 모두 끝남 | `DeclareWait` | 턴 드로우와 같은 5초 선언 대기. 선언하면 턴 종료, 안 하면 5초 뒤 — 메인 행동 전이었다면 턴 계속, 뒤였다면 턴 종료 | 확정 (2026-11-07 — 5초 대기의 적용 범위) |
| `MyTurn` | 제한 시간 종료 & 미제출 | `TurnEnd` | 아무것도 하지 않고 턴 종료 (자동 제출 없음). 그 플레이어의 **연속 시간 초과 횟수 +1** | 확정 |
| `MyTurn` (연속 3턴 시간 초과) | 3번째 시간 초과 | 강제 퇴장 | 최종 사망과 같은 처리 (`01-game-flow` 6절) 뒤 그 플레이어를 방에서 내보낸다 (로비로). 봇에는 적용하지 않는다 | 확정 (2026-11-07) |
| `MyTurn` (메인 행동 전) | 함정 설치 조건 충족 (`04-card.md` 6절) | 상태 변화 없음 | 함정 슬롯에 배치 | 확정 |
| `TurnEnd` | — | 다음 생존 플레이어의 `WaitingTurn` | 턴 이동 | 확정 |

```
WaitingTurn → MyTurn → (Draw → [손패 10장이면 DeclareWait 5초] | PlayAction → Resolving | 시간 초과) → TurnEnd → 다음 플레이어
```

* 연속 시간 초과 횟수는 **방장**이 플레이어마다 센다. **시간 초과가 아닌 턴 종료**(뽑기 · 카드 사용 · 선언 대기 뒤 종료)가 한 번 있으면 0 으로 돌아간다. 스킵된 턴은 시작하지 않은 것(7절)이라 세지 않는다. 연결 끊김으로 넘어간 턴은 시간 초과로 센다 (10절). (확정 2026-11-07 — N = 3 · 세는 방법 모두)

## 6. 턴 순서 결정 (확정 + 제안)

1. 게임 시작 시 마스터가 참가자 목록을 **무작위로 섞어** 턴 순서 배열을 만든다. (확정: 무작위)
2. 이 배열을 모든 클라이언트에 1회 브로드캐스트한다. (제안)
3. 이후 턴 이동은 이 배열에서 **진행 방향**으로 다음 **생존** 플레이어를 찾는다. (확정)
4. **진행 방향**은 정방향(배열 순) · 역방향 둘 중 하나로, 게임 시작은 정방향이다. 방향은 마스터가 들고 한 판 동안 유지한다 — 반전 카드가 바꾸고, 다시 반전하면 정방향으로 돌아온다. 다른 카드의 「다음 플레이어」(손패 무작위 N장을 다음 플레이어에게 넘기는 카드(A10) 등)도 이 방향을 따른다. (확정 2026-11-07)

## 7. 턴 이동 규칙

| 상황 | 처리 | 구분 |
| --- | --- | --- |
| 정상 종료 | 다음 생존 플레이어로 이동 | 확정 |
| 현재 턴 플레이어가 사망 확정 | 해당 턴 종료 후 다음 생존 플레이어로 | 확정 |
| 다른 플레이어 사망 | 처리 후 기존 턴 플레이어 진행으로 복귀 | 확정 |
| 최종 사망 플레이어 | 턴 순서에서 제외. 사망 대기 중에는 게임이 멈추므로(`06` 8절) 순서를 건드리지 않는다 | 확정 (2026-10-30) |
| 현재 턴 플레이어가 퇴장 | 다음 플레이어에게 턴 이동 | 확정 |
| 드로우로 손패가 정확히 10장 — 선언 대기 | 드로우 뒤 턴이 바로 끝나지 않고 **5초** 선언 대기가 열린다 (4절). 5초 안에 찹츄 선언이 승인되면 **그 순간**, 누르지 않으면 **5초 뒤** 다음 생존 플레이어로. 이유: 뽑으면 턴이 끝나 내 턴에는 선언할 틈이 없고, 「턴 넘기기」 입력은 없다(8절). 남의 턴에 선언하면 턴 이동에 영향 없다 (그 턴은 그대로). 봇도 같다 (`18-bot` 7-5) | 확정 (2026-11-07, PM) |
| 턴 시작 때 이미 10장인데 선언하지 않은 사람 | 특별 규칙 없음 — 선언은 언제든 되고(07 4.1) 턴은 보통대로 간다. 남의 턴에 10장이 됐을 때 선언했으면 이 턴 시작에 이미 이겼으므로, 선언을 미룬 것은 본인 손해다. 봇은 남의 턴에 10장이 되면 즉시 선언하므로 이 경우가 없다 | 확정 (2026-11-07) |
| 턴 스킵 효과 — 대상의 다음 턴을 건너뛰게 하는 행동 카드(A01) · 나를 노린 행동 카드를 취소하고 시전자의 다음 턴을 건너뛰게 하는 함정(T05) | 해당 플레이어에게 "다음 턴 스킵"을 **설정**. 겹쳐 받아도 쌓이지 않고 1회만 건너뜀. 스킵된 턴은 시작하지 않은 것으로 본다 — 찹츄 승리 판정 · 턴 시작 드로우가 없다. 스킵 직후 「턴 스킵된 후」 함정 시간 (`04` 6절) | 확정 (2026-10-30) / 확정 (스킵된 턴 처리, 2026-11-06) |
| 턴 시작 추가 드로우 — 턴이 스킵된 뒤 다음 실제 턴에 N장 더 뽑는 함정(T15) | 「다음 실제 턴 시작 시 N장」 — 스킵되지 않은 다음 내 턴이 시작될 때 뽑는다. 메인 행동이 아니다 | 확정 (2026-11-06) |
| 턴 방향 반전 — 진행 방향을 뒤집는 행동 카드(A07) | 진행 방향을 반대로 (6절 #4). 반전한 뒤 턴 종료 시 **반대 방향의 다음 생존 플레이어**로 간다. 생존자가 **2명**이면 반전해도 다음 사람이 같아 카드가 헛되므로, 이때는 **다음 플레이어를 건너뛰어 내 턴이 다시 온다** (Uno 의 2인 리버스와 같다) | 확정 (2026-11-07) |

> 방향 개념은 방향 반전 카드(A07) 와 손패 무작위 N장을 다음 플레이어에게 넘기는 카드(A10) 가 요구해서 넣었다 (2026-11-07). 반전은 3 ~ 4인에서 「내 다음에 공격할 사람」을 바꾸는 카드이고, 2인에서는 연속 턴 카드가 된다.

## 8. 입력

| 입력 | 동작 | 조건 |
| --- | --- | --- |
| 덱 탭 | 드로우 요청 | 자신의 턴 + 메인 행동 미사용 |
| 카드 드래그 → 드롭 영역 | 행동 카드 사용 요청 | 자신의 턴 + 메인 행동 미사용 + 카드 조건 충족 |
| 함정 슬롯으로 드래그 | 함정 설치 요청 | 자신의 턴 + 메인 행동 전 + 빈 슬롯 존재 | 
| 찹츄 버튼 | 찹츄 선언 요청 (`07-win-condition` 4.1) | 손패 정확히 10장 — 남의 턴 포함. 선언 대기 5초 동안 받는 **유일한** 입력 |

> 함정 설치 입력 방식은 **미정**.

> **「턴 넘기기」 입력은 없다** (확정 2026-11-07, PM). 내 턴에 할 수 있는 입력은 위 표가 전부다 — 할 것이 없으면 20초 뒤 턴이 넘어간다 (4절). 드로우로 10장이 되면 5초 선언 대기가 열리고, 선언하거나 5초가 지나면 턴이 끝난다 (4절 · 7절, 확정 2026-11-07).
