## 4. 동작

| 처리 | 동작 |
| --- | --- |
| 방 생성 | **개발자 모드**의 로비 「방 만들기」(`14-lobby-ui` 5절) — 고르는 팝업 없이 **비공개**로 만든다 (5절 #7). 랜덤 코드를 만들어 방 이름으로 쓴다. 최대 4명, 열림(`IsOpen = true`), 공개 여부 = `IsVisible` (공개 true · 비공개 false). 「혼자 하기」 도 같은 방 생성 + 봇 3 (`18-bot` 10절). 확정 (2026-11-07 비공개 · 2026-11-11 팝업 없음 · 2026-11-26 개발자 모드만, PM) |
| 코드 중복 (에러 32766) | 자동으로 다시 생성 시도 |
| 방 참가 | 입력 코드의 앞뒤 공백을 지우고 대문자로 바꿔 참가. 공개 · 비공개 모두 코드로 들어올 수 있다. 로비 「코드로 참가」 는 **개발자 모드**에서만 (`14-lobby-ui` 5절, 2026-11-26 PM). 초대 수락 · 친구 「참가」 도 같은 호출 (`13-friend` 4절) |

| 공개 ↔ 비공개 변경 | **방장**이 방 안의 토글로 바꾼다 (시작 전만, 개발자 모드 방만). 방장이 `IsVisible` 을 바꾸면 전원 화면의 표시가 바뀌고 로그 「공개로 변경」 / 「비공개로 변경」 한 줄. 매치 방은 바꿀 수 없다 — 토글이 없다 (2026-11-07 확정, 5절 #7 · 2026-11-26 매치 방) |
| 참가 실패 | 실패 이유를 팝업으로 알린다 (문구는 14-lobby-ui) |
| 방 씬 이동 | 입장에 성공하면 방 씬을 연다 |
| 게임 시작 | 방장이 방을 닫고(참가 · 검색 불가) 전원을 게임 씬으로 이동시킨다 |
| 매치 시작 (매치 방만) | ① **방장**이 매치 방을 만들 때 시작 시각 = 지금 + **15초** 를 방 속성 `matchAt`(서버 시각)에 적는다. ② 사람 **4명**이 다 차면 방장이 시작 시각을 **지금 + 3초**로 당긴다 — 누가 모였는지 보이게. ③ 남은 시간이 **3초 미만**일 때 사람이 들어오면 방장이 시작 시각을 **들어온 때 + 3초**로 미룬다. ④ 시각이 되면 방장이 빈자리를 봇(난이도 **보통**)으로 채우고 **1.5초** 뒤 「게임 시작」 과 같은 처리를 한다 — 봇이 든 칸을 보고, 봇 목록이 전원에게 닿게. 사람이 1명이어도 시작한다 = 봇 3. ⑤ 방장이 나가면 새 방장이 방 속성의 시각을 이어 센다. 매치 방에는 「게임 시작」 버튼이 없다 (화면은 `16-room-ui-full` 3절 #17 · 7-7). 확정 (2026-11-26 PM) — 2026-11-07 「빠른 시작 방 · 2명 이상이면 30초 카운트다운 자동 시작 · 방장 즉시 시작」 을 대체 (코드에 만든 적 없음). 개발자 모드 방은 방장만 시작한다 |
| 내보내기 | 방장이 대상을 정해 요청 → Photon 의 플레이어 추방(방에서 끊기)으로 대상이 방을 나간다. 대상은 로비로 가고 안내 팝업을 본다. 로그 「○○님을 내보냈어요.」 (2026-11-07 확정, 5절 #9) |
| 시작 직후 1명만 남음 | 방장이 시작을 누른 뒤 게임 씬이 뜨기 전에 퇴장으로 **봇 포함 1명**이 되면 게임을 시작하지 않는다. 방장이 방을 다시 열고(`IsOpen = true`, 공개 여부는 그대로) 전원이 방 화면에 머물거나 돌아온다 — 룸 복귀 (2026-11-07 확정, `16-room-ui-full` 9절) |
| 게임 종료 | 방을 **다시 열지 않는다** — 닫힌 채(`IsOpen = false`. 공개 여부도 그대로)로 방장이 전원을 **결과 화면**(새 씬)으로 옮긴다. 결과 화면에서 「한 판 더!」 로 전원이 준비하면 같은 방 · 같은 봇으로 새 판, 「로비로」 · 45초 자동 이동이면 그 사람이 방을 나간다 — 방 화면으로 돌아가는 길은 없다. 봇은 방에 남아 스스로 준비한다 (`07-win-condition` 11-1) — 확정 (2026-11-17, PM. 2026-11-07 「방을 다시 열고 방으로 · 지난 판 결과」 폐기) |

## 6. 상태 흐름 (확정 — 5절)

```
Lobby ──(랜덤 매칭)──→ Room(매치 방 — 자리가 있는 매치 방이면 참가자, 없으면 새로 만들어 방장)
Room(매치 방) ──(시작 시각 → 빈자리 봇 채움 → 1.5초)──→ GameScene
Lobby ──(개발자 모드: 방 만들기 — 비공개로 시작 · 혼자 하기)──→ Room(방장)
Lobby ──(개발자 모드: 코드 입력 / 초대 수락)──→ Room(참가자)
Room  ──(방장 토글)──→ Room(공개 ↔ 비공개, 개발자 모드 방만)
Room  ──(시작 버튼, 개발자 모드 방)──→ GameScene
Room  ──(시작 직후 퇴장으로 1명)──→ Room (방 다시 열림)
Room  ──(나가기 · 내보내짐)──→ Lobby
```
