## 4. 동작

| 처리 | 동작 |
| --- | --- |
| 방 생성 | 로비 「방 만들기」 팝업(`22-popup-ui` 2-1)에서 **공개 / 비공개**를 고르고 「만들기」. 랜덤 코드를 만들어 방 이름으로 쓴다. 최대 4명, 열림(`IsOpen = true`), 공개 여부 = `IsVisible` (공개 true · 비공개 false). 기본 선택은 **비공개** (확정 2026-11-07, 5절 #7 — 코드 방은 보통 친구용) |
| 코드 중복 (에러 32766) | 자동으로 다시 생성 시도 |
| 방 참가 | 입력 코드의 앞뒤 공백을 지우고 대문자로 바꿔 참가. 공개 · 비공개 모두 코드로 들어올 수 있다 |
| 랜덤 매칭 (빠른 시작) | 자리가 있는 **공개**(`IsVisible = true` · `IsOpen = true`) 방에 참가. 없으면 새 방 생성 — **확정 (2026-09-25, MVP 포함)**. 랜덤 매칭으로 **새로 만들어진** 방은 **무조건 공개, 바꿀 수 없다**(2026-11-07 확정) 그리고 「빠른 시작 방」 표시를 방 정보에 둔다 (자동 시작 대상, 5절 #2) |
| 공개 ↔ 비공개 변경 | **방장**이 방 안의 토글로 바꾼다 (시작 전만). 방장이 `IsVisible` 을 바꾸면 전원 화면의 표시가 바뀌고 로그 「공개로 변경」 / 「비공개로 변경」 한 줄. 빠른 시작 방은 바꿀 수 없다 (2026-11-07 확정, 5절 #7) |
| 참가 실패 | 실패 이유를 팝업으로 알린다 (문구는 14-lobby-ui) |
| 방 씬 이동 | 입장에 성공하면 방 씬을 연다 |
| 게임 시작 | 방장이 방을 닫고(참가 · 검색 불가) 전원을 게임 씬으로 이동시킨다 |
| 자동 시작 (빠른 시작 방만) | 랜덤 매칭으로 **새로 만들어진 방**에서 봇 포함 **2명 이상**이 된 순간 방장이 30초 카운트다운을 시작하고 방 정보로 마감 시각을 전원에게 알린다. 0초가 되면 방장이 「게임 시작」과 같은 처리를 한다. 방장은 그 전에도 「게임 시작」을 눌러 즉시 시작할 수 있다. 누가 나가 1명이 되면 카운트다운을 취소하고, 다시 2명이 되면 30초부터 다시 센다. 방장이 바뀌면 새 방장이 남은 시간을 이어 센다 (2026-11-07 확정, 화면은 `16-room-ui-full` 7-7). **사람이 공개로 만든 방**에는 카운트다운이 없고 방장만 시작한다 (확정 2026-11-07 — 방장이 자리에 있는 방이다) |
| 내보내기 | 방장이 대상을 정해 요청 → Photon 의 플레이어 추방(방에서 끊기)으로 대상이 방을 나간다. 대상은 로비로 가고 안내 팝업을 본다. 로그 「○○님을 내보냈습니다.」 (2026-11-07 확정, 5절 #9) |
| 시작 직후 1명만 남음 | 방장이 시작을 누른 뒤 게임 씬이 뜨기 전에 퇴장으로 **봇 포함 1명**이 되면 게임을 시작하지 않는다. 방장이 방을 다시 열고(`IsOpen = true`, 공개 여부는 그대로) 전원이 방 화면에 머물거나 돌아온다 — 룸 복귀. 빠른 시작 방이면 카운트다운도 취소 (2026-11-07 확정, `16-room-ui-full` 9절) |
| 게임 종료 | 승리 판정 즉시 방장이 방을 다시 연다(`IsOpen = true`. 공개 여부는 시작 전 값 그대로 — 비공개 방은 비공개로 남는다). 전원은 **결과 화면**을 보는 상태로 방에 남아 있고, 각자 「방으로」를 눌러 자기 화면만 방 화면으로 바꾼다 — 자동 이동 없음. 방장이 다음 판을 시작하면 결과 화면을 보던 사람도 참가한다. 방장은 「지난 판 결과」 요약을 Room CustomProperties 에 저장한다. 봇은 방에 남는다 (`07-win-condition` 11절) — 확정 (2026-11-07) |

## 6. 상태 흐름 (확정 — 5절)

```
Lobby ──(방 만들기: 비공개로 시작)──→ Room(방장)
Lobby ──(코드 입력/초대)──→ Room(참가자)
Lobby ──(랜덤 매칭)──→ Room(빈 공개 방이 있으면 참가자, 없으면 방장 — 공개 고정 · 빠른 시작 방)
Room  ──(방장 토글)──→ Room(공개 ↔ 비공개, 빠른 시작 방 제외)
Room  ──(시작 버튼)──→ GameScene
Room  ──(빠른 시작 방 · 2명 이상 30초 경과)──→ GameScene
Room  ──(시작 직후 퇴장으로 1명)──→ Room (방 다시 열림)
Room  ──(나가기 · 내보내짐)──→ Lobby
```
