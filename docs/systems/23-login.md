## 1. 목적

플레이어가 **가입 절차 없이** 게임을 시작하고, 원하면 계정을 기기 밖으로 옮길 수 있게 한다. 닉네임 · 장착 · 통계 · 친구가 **서버에** 남아 앱을 다시 설치하거나 기기를 바꿔도 이어진다(연동한 경우). 스토어가 요구하는 계정 삭제 · 약관 동의 · 최소 버전 · 점검을 여기서 정한다.

## 2. 판정 주체

**방장(마스터 클라이언트) 판정은 없다.** 계정은 게임 규칙이 아니다. 판정은 **UGS 서버**와 **클라이언트(해당 플레이어 기기)** 둘로 나뉜다.

- 12 4-2 가 허용 문자를 한글 완성형 · 영문 · 숫자 · 가나 · 한자로 막으므로, 실제 입력에서 1 · 4 · 7 은 조합 중이거나 붙여넣기한 경우에만 의미가 있다. 그래도 **서버는 같은 순서를 전부** 돈다 (클라이언트 우회 대비).
- 검사는 **같은 규칙 · 같은 목록**을 클라이언트와 서버가 쓴다. 규칙이 바뀌면 둘을 같이 고친다 — 서버는 `server/cloud-code/SetNickname.js`.
- 서버도 12 4-2 허용 문자 검사를 **먼저** 돌린다 — 공백 · 특수문자 · 자모 · 초성은 거기서 막혀 1 · 4 · 7 단계에 남는 입력이 없다 (2026-11-26). 2-1 의 번체 → 간체 맞춤은 아직 없다 — 그때까지 금칙 목록에 두 글꼴을 다 넣는다.

### 8-3. 어디서 검사하나

| 때 | 누가 | 결과 |
| --- | --- | --- |
| 입력 중 · 「시작」 「변경」 탭 | **클라이언트** (Remote Config 로 받은 목록) | 걸리면 즉시 에러 문구, 서버에 보내지 않는다 |
| 저장 요청 | **UGS Cloud Code** — 저장 직전에 같은 검사 | 걸리면 거절, 저장하지 않는다. 클라이언트는 같은 에러 문구 |
| 서버가 금칙어 목록을 못 읽음 | **UGS Cloud Code** | 저장하지 않는다 — 「잠시 후 다시 시도해 주세요.」 (검사 없이 통과시키지 않는다) — 제안 (2026-11-26) |
| 닉네임 저장 경로 | 클라이언트는 Cloud Save 에 닉네임을 **직접 쓰지 않는다** — Cloud Code 만 보호 칸(7-8)에 쓴다 | 서버 검사를 건너뛸 수 없다. 네트워크 서버(Photon)에 보내는 표시 이름은 클라이언트가 정하므로 고친 클라이언트는 다른 이름을 보일 수 있다 (`09` 13절) |
