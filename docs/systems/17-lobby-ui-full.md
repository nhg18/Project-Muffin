# 17. 로비 화면 UI — 확장 (로그인 · 친구 이후, 페이지 3장)

**최종 수정일**: 2026-11-03
**분류**: Optional (`development-plan` 기능 12 「로그인 · 친구」 이후에 켠다. 그 전에는 이 문서의 요소를 화면에 두지 않는다)
**출처**: 2026-11-03 플랜 세션 초안. 노션 「📋 개발 기획서」 11절(친구 — [`13-friend.md`](13-friend.md) 로 이관됨) · 12절(설정 / 프로필 **제안**) · 「➡️ Game Flow」 2-2 점선 노드 · [`store-release.md`](../store-release.md) 결정 3 · 4절
**전제**: 로그인 문서(미작성)와 백엔드 선택이 먼저다. 이 문서는 **백엔드 = Unity Gaming Services Authentication + Friends** 를 `가정` 하고 쓴다. 전제가 바뀌면 2절 · 5절 · 12절을 고친다.

> MVP 로비([`14-lobby-ui.md`](14-lobby-ui.md))의 배경 · 캔버스 · 버튼 **동작**은 그대로다. 이 문서는 **배치를 모바일 기준으로 다시 잡고**(버튼 3개를 우하단 엄지 범위로), 로비를 **페이지 3장(상점 · 홈 · 보관함) + 하단 탭 바 + 좌우 넘김**으로 넓히며, 가장자리 UI 와 팝업을 더한다. 보관함 · 상점의 **내용**은 [`19-character-items.md`](19-character-items.md), 이 문서는 **화면**만. 14 의 7-1 배치는 이 문서를 적용하는 시점에 이 문서 7-1 로 바뀐다. 친구 **규칙**(요청 · 차단 · 초대 조건)은 [`13-friend.md`](13-friend.md), 방 **규칙**은 [`08-room.md`](08-room.md) 가 기준이고, 이 문서는 로비 **화면**만 다룬다.

## 1. 목적

로그인 · 친구가 생긴 뒤의 로비. 플레이어가 **자기 정보를 확인하고(프로필), 친구를 맺고 초대를 받고(친구), 소리 · 계정을 관리한다(설정).** 방을 만들고 참가하는 버튼의 **동작**은 14-lobby-ui 5절 그대로이고, **자리와 크기**는 이 문서가 다시 정한다 — 가로 폰에서 엄지가 닿는 **아래 모서리**에 둔다.

로비는 **한 씬 안의 페이지 3장**이다 — 왼쪽 **상점**, 가운데 **홈**(캐릭터 · 플레이 버튼), 오른쪽 **보관함**(캐릭터 · 이펙트 꾸미기). 하단 탭 바로 고르거나 좌우로 넘긴다. 짧은 일(설정 · 프로필 · 친구)은 어느 페이지에서든 **팝업**, 방 · 게임은 지금처럼 **씬 이동**.

모바일 로비에 흔히 있는 것 중 **이 게임에 지금 필요한 것만** 고른다. 뺀 것과 이유는 11절.

## 2. 판정 주체

| 대상 | 판정 · 저장 | 로비 화면이 하는 일 |
| --- | --- | --- |
| 친구 목록 · 요청 · 차단 · 친구 코드 · 전적 · 닉네임 | **친구 서버(백엔드)** 가 저장하고 판정한다 | 요청만 보내고 결과를 **표시**한다 |
| 온라인 · 게임 중 · 어느 방인지 | 네트워크 서버(접속 여부 · 방 이름) + 친구 서버(상태) | 표시 |
| 초대 보내기 · 받기 · 30초 만료 | 친구 서버 (13-friend 4절) | 배너 표시 · 수락 · 거절 |
| 초대 수락 뒤 방 참가 | 네트워크 서버 — 08-room 4절 「방 참가」 와 같은 경로 | 로딩 팝업 → 결과 표시 |
| 소리 · 알림 켜기/끄기 | **로컬**(기기 저장) | 즉시 적용 |

**방장(마스터 클라이언트) 판정은 없다.** 로비에는 방이 없다. 09-network 의 방장 원칙은 방 · 게임에만 적용된다.

- 페이지 전환: 홈 · 상점 · 보관함의 **페이지 안 내용**만 가로로 미끄러진다(0.25초). 칩 · 버튼 · 배너 · 탭 바 · 배경은 움직이지 않는다.
- 캐릭터는 배경 일러스트 위, 가장자리 UI 아래 층. 배경 캐릭터(콜로세움 키 아트의 치와와)와 겹치지 않게 배경 그림의 주요 부분은 가운데 ~ 오른쪽에 두거나 로비 전용 배경을 쓴다 (14-lobby-ui 미정 #1).
- 4:3 태블릿(캔버스 1920 × 1440)에서는 위아래만 넓어진다. 가장자리 UI 는 모서리를 따라가므로 추가 작업 없음. 20:9 폰(2400 × 1080)은 좌우가 넓어져 묶음과 칩 사이가 더 벌어질 뿐이다.
