# 13. 친구 시스템

**최종 수정일**: 2026-11-07
**분류**: Optional (MVP 밖 — `development-plan` M7 로그인 · 친구, 12/17 ~ 12/30 에 착수. 로그인 문서가 먼저다)
**출처**: 노션 「📋 개발 기획서」 11절 (이관)

---

## 1. 목적

닉네임·친구 코드 기반으로 친구를 맺고, 온라인 상태의 친구를 방으로 초대하는 기능을 정의한다.
**Optional 분류이며 현재 구현 대상이 아니다.** 나중에 착수할 때 참고할 규칙만 먼저 옮겨 둔다.

---

## 2. 친구 요청 (확정)

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 검색 | 닉네임 또는 친구 코드로 검색 | 확정 |
| 검색 제외 대상 | 본인, 차단한 유저 | 확정 |
| 요청 → 수락/거절 | 상대가 수락/거절 | 확정 |
| 동시 요청 | 양쪽이 동시에 요청하면 자동으로 친구 등록 | 확정 |
| 같이 게임한 사람에게 요청 | 방 화면의 플레이어 정보 팝업(칸 탭, [`16-room-ui-full.md`](16-room-ui-full.md) 7-5)에서 「친구 추가」 로 요청한다. 검색 없이 그 사람을 바로 대상으로 삼는 것만 다르고, 그 뒤(수락 · 거절 · 동시 요청 · 차단 · 한도)는 위 규칙과 같다. 봇 · 본인 · 이미 친구 · 차단 관계에는 버튼이 없다 | 확정 (2026-11-07) |
| 요청 알림 | 받는 쪽 로비에서: 친구 버튼 **배지 +1** + 토스트 「{닉네임} 님이 친구 요청을 보냈습니다.」 (`17-lobby-ui-full` 6절 · 8절). 별도 알림 화면 · 푸시 알림은 없다 | 확정 (2026-11-07, `17` 제안 채택) / 제안 (방 · 게임 중에 받으면 토스트 없이 배지만 — 로비로 돌아왔을 때 배지로 안다) |
| 친구 최대 인원 | **50명.** 한도에 닿으면 「요청」 버튼 비활성 + 토스트 「친구는 50명까지 추가할 수 있어요.」 (`17` 10절). 상대가 한도면 요청이 서버에서 거절되고 같은 문구를 보낸 쪽이 본다 | 확정 (2026-11-07) |

## 3. 차단

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 차단 시 | 요청·초대가 막히고 상대 목록에서도 사라짐 | 확정 |
| 차단 해제 후 | 친구 관계가 자동 복원되지 않음. 다시 요청부터 진행 | 확정 |

## 4. 방 초대

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 초대 가능 조건 | 상대가 온라인 + 게임 중이 아님 + 다른 초대를 수락하지 않은 상태 | 확정 |
| 만료 | 30초 후 자동 만료 | 확정 |
| 초대 내용 | 보낸 사람 닉네임 + **방 코드**(`08-room` 5절 #3, 영대문자 4자리). 초대는 방 코드를 전달하는 수단이다 | 확정 (2026-11-07) |
| 초대 수락 | 초대에 든 방 코드로 참가하는 것 — 로비 「방 참가」 에 코드를 넣은 것과 **같은 호출**(`08-room` 4절 「방 참가」). 별도 초대 전용 참가 경로는 없다. 실패하면 같은 실패 팝업(`08` 7절 문구) | 확정 (2026-11-07, 미정 #4 통합) |
| 친구 따라 들어가기 (「참가」) | 친구 목록에서 방 대기 중인 친구의 행에 「참가」 가 보이고, 누르면 그 친구가 있는 방의 코드로 **같은 호출**로 참가한다. 친구 상태(5절)에 방 코드가 포함되어야 한다. 로비 화면은 `17-lobby-ui-full` 이 적는다 | 확정 (2026-11-07) |

## 6. 친구 코드

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 형식 | **영대문자 + 숫자 6자리.** 헷갈리는 글자 `I` · `O` · `0` · `1` 은 쓰지 않는다 (32종 → 32⁶ ≈ 10억 개) | 확정 (2026-11-07) |
| 생성 | 계정이 만들어질 때 서버가 무작위로 만든다. 이미 있는 코드와 같으면 다시 만든다 | 확정 (2026-11-07) |
| 수명 | **계정에 영구.** 바꾸지 않는다 | 확정 (2026-11-07) |
| 방 코드와 구분 | 방 코드는 영대문자 **4자리**(`08-room` 5절 #3), 친구 코드는 **6자리** — 자릿수로 구분된다. 입력칸은 다르므로(방 참가 팝업 · 친구 검색창) 겹칠 일은 없다 | 확정 (2026-11-07) |
| 입력 | 소문자로 넣어도 대문자로 바꿔 검색한다. 앞뒤 공백 제거 | 확정 (방 코드와 같은 규칙, `08` 4절) |
| 표시 | 본인에게만 보인다 (`17-lobby-ui-full` 3절 #9). 글꼴은 고정폭(`21-font` 4절) | 확정 |
