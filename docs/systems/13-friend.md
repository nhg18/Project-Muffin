# 13. 친구 시스템

**최종 수정일**: 2026-09-23
**분류**: Optional (현재 개발 범위 밖 — Core/MVP 완료 후 착수)
**출처**: 노션 「📋 개발 기획서」 11절 (이관)

---

## 1. 목적

닉네임·친구 코드 기반으로 친구를 맺고, 온라인 상태의 친구를 방으로 초대하는 기능을 정의한다.
**Optional 분류이며 현재 구현 대상이 아니다.** 나중에 착수할 때 참고할 규칙만 먼저 옮겨 둔다.

---

## 2. 친구 요청 (확정)

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 검색 | 닉네임 또는 친구 코드로 검색 | 확정 |
| 검색 제외 대상 | 본인, 차단한 유저 | 확정 |
| 요청 → 수락/거절 | 상대가 수락/거절 | 확정 |
| 동시 요청 | 양쪽이 동시에 요청하면 자동으로 친구 등록 | 확정 |

---

## 3. 차단

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 차단 시 | 요청·초대가 막히고 상대 목록에서도 사라짐 | 확정 |
| 차단 해제 후 | 친구 관계가 자동 복원되지 않음. 다시 요청부터 진행 | 확정 |

---

## 4. 방 초대

| 규칙 | 내용 | 구분 |
| --- | --- | --- |
| 초대 가능 조건 | 상대가 온라인 + 게임 중이 아님 + 다른 초대를 수락하지 않은 상태 | 확정 |
| 만료 | 30초 후 자동 만료 | 확정 |

---

## 5. 동기화

| 데이터 | 공개 범위 | 구분 |
| --- | --- | --- |
| 친구 상태(온라인/오프라인/게임 중 등) | 모든 클라이언트에 실시간 동기화 | 확정 |
| 방 정보(초대용) | 모든 클라이언트에 실시간 동기화 | 확정 |

노션 원문은 권한 모델(누가 판정·전파하는지)을 별도로 명시하지 않는다. 구현 시 [`09-network.md`](09-network.md)의 마스터 권한 원칙을 그대로 적용한다 — **가정**.
