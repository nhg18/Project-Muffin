## 2. 한 줄 요약

> 카드 10장을 모으면 승리. 끝까지 버틸 수 있다면요.

플레이어는 카드 10장을 모아 승리를 노리지만, 승리에 가까워질수록 다른 플레이어들의 집중 견제를 받는다.
함정과 카운터는 자신의 턴이 아니어도 개입할 수 있어 끝까지 상황이 뒤집힌다.
HP 100을 지켜내지 못하면 카드를 모아도 의미가 없다.

## 3. 핵심 규칙 요약

| 항목 | 내용 | 구분 |
| --- | --- | --- |
| 인원 | 2~4인 | 확정 |
| 플레이타임 | 5~10분 | 확정 |
| 승리 조건 | ① 처치 승리: 최후 생존 ② 찹츄 승리: 손패 10장 도달 후 선언, 다음 자신의 턴 시작까지 10장 유지 | 확정 |
| 턴 구조 | 자신의 턴에 **드로우 1장** 또는 **행동 카드 1장 사용** 중 하나만 선택(메인 행동). 함정 설치는 메인 행동이 아님 | 확정 |
| 카드 종류 | 행동 / 함정 / 카운터 | 확정 |
| 반응 시간 | 카드가 처리 대기 상태가 될 때마다 5초 | 확정 |
| 체력 | 초기·최대 HP 100 (정수), 위험 상태 HP 1~20, HP 0 → 사망 대기 → 최종 사망 | 확정 |
| 덱 | 시작 시 **5장** 지급, 소진 시 버림 더미 셔플 후 재생성 | 확정 |
| 함정 슬롯 | 플레이어당 최대 3장 | 확정 |
| 턴 제한 시간 | 20초 | 확정 (2026-09-22 `03-turn.md` 반영) |

> 코드의 초기 손패는 5장으로 맞춰졌다 (`GameStatus.StartHandCount`, 2026-09-23). 상세는 [`05-deck.md`](05-deck.md) 현재 구현 상태.

## 4. 용어 정의

문서와 코드에서 아래 용어를 통일해서 사용한다.

| 한국어 | 영문 (코드) | 의미 |
| --- | --- | --- |
| 손패 | `Hand` | 플레이어가 보유 중인 카드 |
| 덱 | `Deck` | 아직 뽑히지 않은 카드 더미 |
| 버림 더미 | `DiscardPile` | 사용·처리가 끝난 카드 |
| 함정 슬롯 | `TrapSlot` | 설치한 함정 카드가 대기하는 영역 (최대 3) |
| 행동 카드 | `ActionCard` | 자신의 턴에 메인 행동으로 사용 |
| 함정 카드 | `TrapCard` | 설치 후 조건 충족 시 소유자가 수동 발동 |
| 카운터 카드 | `CounterCard` | 처리 중인 카드에 반응해 사용 |
| 메인 행동 | `MainAction` | 턴당 1회의 드로우 또는 행동 카드 사용 |
| 처리 체인 | `ResolveChain` | 카드가 쌓인 순서. 마지막 사용 카드부터 역순 처리 |
| 현재 처리 카드 | `PendingCard` | 체인 최상단, 반응 5초가 돌고 있는 카드 |
| 반응 시간 | `ReactionWindow` | 5초 |
| 찹츄 상태 | `ChapChu` | 손패 10장 선언 상태 |
| 사망 대기 | `DeathPending` | HP 0, 사망 관련 대응 대기 중 |
| 최종 사망 | `Dead` | 대응 후에도 HP 0. 관전 전환 |
| 위험 상태 | `Danger` | HP 1~20 |
| 좌석 | `Seat` | 화면상 플레이어 배치 위치 (0=본인) |
