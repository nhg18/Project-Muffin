## 1. 목적

룸은 **같이 할 사람을 모으고, 모였는지 확인하고, 시작하는** 화면이다. 플레이어가 머무는 시간은 보통 수십 초. 룸이 바로 답해야 할 질문은 셋이다.

| 질문 | 답하는 요소 |
| --- | --- |
| 친구를 어떻게 데려오나 | 방 코드 + 「복사」, 빈 칸 「초대」 (로그인 이후) |
| 누가 들어왔나 · 몇 명인가 | 플레이어 칸 4개 (캐릭터 + 이름표 + 방장 표시), 인원 표시, 로그 |
| 언제 시작하나 | 방장: 「게임 시작」 버튼 / 참가자: 같은 자리의 대기 안내 / 빠른 시작으로 만들어진 방: 자동 시작 카운트다운 |

이 셋 밖의 것(설정 · 채팅 · 준비 · 방 옵션)은 두지 않는다 (10절).

## 2. 판정 주체

| 대상 | 판정 · 저장 | 룸 화면이 하는 일 |
| --- | --- | --- |
| 입장 · 퇴장 · 방장 교체 · 인원 | **네트워크 서버**(Photon) 가 방 상태를 가진다. 방장 판정 없음 | 콜백을 받아 칸 · 인원 · 로그 · 시작 버튼을 갱신한다 |
| 게임 시작 | **방장만** 요청할 수 있다. 방을 닫고 전원을 게임 씬으로 보내는 것도 방장 (08-room 4절) | 방장 화면: 버튼 / 참가자 화면: 대기 안내. 씬 이동은 받는다 |
| 자동 시작 카운트다운 (빠른 시작으로 만들어진 방만) | **방장**이 2명 이상이 된 순간 시작하고 마감 시각을 방 정보로 전원에게 알린다. 0초에 방장이 시작 처리 (08-room 4절 · 5절 #2). 사람이 만든 방(공개 · 비공개)에는 없다 (확정 2026-11-07) | 전원: 남은 초 표시 (7-7). 방장: 그 전에 「게임 시작」 으로 즉시 시작 가능 |
| 공개 ↔ 비공개 토글 | **방장만**, 시작 전만. 방 속성 `IsVisible` 변경 (08-room 5절 #7). 빠른 시작으로 만들어진 방은 공개 고정 — 토글 없음 | 전원: 방 코드 옆 「공개」 / 「비공개」 글자 갱신 + 로그 한 줄 (7-1) |
| 방장 위임 | 네트워크 서버 기본 동작 — 남은 사람 중 먼저 들어온 사람 (08-room 5절 #5) | 표기 갱신 + 새 방장에게 토스트 |
| 플레이어 내보내기 | **방장만** 요청. Photon 의 플레이어 추방으로 대상이 방을 나간다 (08-room 5절 #9, 확정 2026-11-07) | 방장 화면에만 입력. 대상은 로비로 + 안내 |
| 캐릭터 · 이펙트 공개 | **방 입장 때 1회**, 각자가 자기 장착 번호 5개를 모두에게 (19 2절). 방장 판정 없음 | 받은 번호로 칸의 캐릭터를 그린다. 모르는 번호는 기본 |
| 방 코드 복사 | **로컬** (OS 클립보드). 「공유」(OS 공유 시트) 는 없다 — Future | 즉시 |
| 친구 초대 보내기 · 받기 · 30초 만료 | **친구 서버** (13-friend 4절) | 요청 · 배너 표시 · 수락 · 거절 |
| 친구 추가 (칸 탭 → 「친구 추가」) | 친구 서버 (13-friend 2절 「같이 게임한 사람에게 요청」) | 요청 · 결과 토스트 |
| 연결 끊김 (다른 사람) | 네트워크 서버가 끊김을 알린다. 방 **대기 중**에는 **즉시 퇴장** — 자리를 남기지 않는다 (08-room 7절, 확정 2026-11-07). 자리를 유지하는 것은 게임 중만 (`09-network` 12절) | 「누군가 퇴장」 과 같다 — 칸을 비우고 뒤 칸을 당긴다 (6절) |
| 연결 끊김 (나) | 네트워크 서버 | 로비로 이동 + 안내. 돌아가려면 코드로 다시 참가한다 — 방 대기 중에는 재접속이 없다 (08-room 7절) |
| 「지난 판 결과」 | **방장**이 게임 종료 때 마지막 1판 요약을 Room CustomProperties 에 저장한다 (`07-win-condition` 11-5, 확정 2026-11-07) | 버튼을 눌러 요약을 읽기만 한다 |

**게임 규칙 판정은 룸에 없다.** 09-network 의 방장 원칙은 시작 요청 · 자동 시작 · 내보내기 세 입력에만 걸린다.

## 3. 핵심 규칙

| # | 규칙 | 구분 |
| --- | --- | --- |
| 1 | **동작하는 기능만 둔다.** 「로그인 이후」 요소는 친구 서버가 붙기 전에는 화면에 두지 않는다 | 확정 (14-lobby-ui 3절 #1 · 08-room 5절 #7) |
| 2 | **시작은 방장만, 2명 이상일 때.** 1명이면 버튼은 보이되 비활성 + 이유 글자 | 확정 (08-room 5절 #1 · #2) |
| 3 | 참가자에게는 시작 버튼 **자리에 대기 안내**("방장이 시작하면 바로 시작돼요")를 둔다. 눌리지 않는 비활성 버튼을 보이지 않는다 | 제안 — "보이는데 안 눌리는 UI" 금지와 같은 원칙 |
| 4 | **준비(Ready) 없음.** 방 설정은 **공개 여부 하나** — 방 코드 옆에 「공개」 / 「비공개」 글자(전원), 방장에게는 토글 (시작 전만). 인원 4 는 고정 | 확정 (08-room 5절 #6 · #7, 공개 여부 2026-11-07) |
| 5 | 방장이 나가면 **위임**. 방장 표시 · 시작 버튼 · 대기 안내가 전원 화면에서 즉시 바뀌고, 새 방장에게만 토스트 | 확정 (위임, 08-room 5절 #5) / 제안 (토스트) |
| 6 | 플레이어 칸은 **4개 고정**, **입장 순서**로 채운다. 순서는 모든 클라이언트에서 같다 (방장 = 1번 칸이 아니다 — 방장은 표시로 구분). 내 칸에는 「나」 표시. **인게임의 「나를 먼저(0번 자리)」(02-player 3절) 와 다르다** — 룸에는 적용하지 않는다 | 확정 (2026-11-07) — 서로 말로 가리킬 때 "두 번째 칸" 이 같은 사람이어야 한다 |
| 7 | 칸마다 그 플레이어가 **장착한 캐릭터**(+ 오라)가 선다. 지금은 기본 캐릭터 1종 | 확정 (표시 — 19 3절 #8 합의 · 분류 MVP) / 제안 (오라 · 장착 반영은 로그인 이후) |
| 8 | 방 코드는 **항상 보이고**, 한 번 탭으로 **복사**한다. 「공유」(OS 공유 시트) 버튼은 **없다** — 모든 플랫폼에서 복사만. 네이티브 공유는 Future | 확정 (2026-11-07) — 룸에 들어온 사람이 가장 먼저 하는 일이 "코드 보내기" 다 |
| 9 | 로그는 **입장 · 퇴장 · 방장 교체** 3종, 최대 30줄. 화면에는 **최근 몇 줄만** 보이고 탭하면 전부 펼친다 | 확정 (3종 · 30줄, 08-room 5절 #4) / 제안 (접기 · 펼치기) |
| 10 | 룸 안에서 **바꾸는 것은 없다** — 닉네임 · 캐릭터 · 이펙트 장착은 로비에서만. 룸은 보여 주기만 한다 | 확정 (19 3절 #7 합의 → 제안 승계) |
| 11 | 팝업은 **한 번에 하나.** 모달 규칙 · 겹침 · 바탕 탭(닫히지 않음) 은 `22-popup-ui` 1절 #3 ~ #5 를 따른다 | 확정 (바탕 탭, 2026-11-07) / 제안 (나머지, `22` 1절) |
| 12 | Android 뒤로가기 = ① 열린 팝업 닫기 (`22` 1절 #5) → ② 팝업이 없으면 **나가기 버튼과 같은 동작** (확인 팝업 포함) | 제안 |
| 13 | 시작은 **방장 탭 → 방 닫힘(참가 · 랜덤 매칭 대상 제외) → 전원 「시작 중」 표시 → 게임 씬.** 시작이 걸린 뒤에는 누구도 나가기 · 초대 입력을 쓸 수 없다 | 확정 (방 닫기, 08-room 5절 #8) / 제안 (시작 중 표시 · 입력 잠금) |
| 14 | 입장 · 퇴장 때 칸은 **즉시** 바뀐다. 열림 · 닫힘 연출은 없다. 룸 입장 이펙트(19 5절 「입장」)는 룸에서 **재생하지 않는다** — 인게임 입장 때만 | 제안 (즉시) / 확정 (입장 이펙트 없음, 2026-11-07) |
| 15 | 터치 영역 44pt · 글자 11pt 이상 (15-screen 5절). 가장자리 요소는 Safe Area 안 | 확정 (기존) |
| 16 | 비공개 정보 없음 — 룸의 모든 표시(닉네임 · 캐릭터 · 방장 · 인원 · 로그 · 공개 여부)는 **방 안 전원에게 같다.** 친구 서버 정보(친구인지 · 친구 코드)는 본인 화면에만 | 제안 |
| 17 | **빠른 시작(랜덤 매칭)으로 새로 만들어진 방은 공개 고정.** 토글은 **숨기고**(꺼진 상태로도 보이지 않는다) 글자만 「공개 · 빠른 시작」 으로 보인다 — 눌리지 않는 토글을 보이지 않는다 (#1 원칙) | 확정 (공개 고정 · 숨김, 2026-11-07) / 제안 (「공개 · 빠른 시작」 문구) |

## 4. 주요 수치 (시간 · 개수만 — 크기 · 색 없음)

## 7. UI 요소별 명세

요소마다 **무엇 · 언제 · 내용 · 동작 · 상태 · 시점**. 자리는 "어느 묶음에 속하는가" 만 적고 좌표 · 크기는 적지 않는다.

### 7-0. 구성 개요 (묶음만 — 배치 수치 · 디자인 아님)

```
[나가기]   방 코드 ABCD [복사]  비공개 [토글]   인원 2 / 4   [지난 판 결과]
      ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
      │캐릭터│ │캐릭터│ │ 빈 칸 │ │ 빈 칸 │     ← 입장 순서, 4칸 고정
      │이름표│ │이름표│ │ 초대  │ │ 초대  │
      │ 👑 나 │ │      │ │      │ │      │
      └──────┘ └──────┘ └──────┘ └──────┘
 로그 (최근 3줄, 탭 → 펼침)      [게임 시작] / "방장이 시작하면 바로 시작돼요" / "{n}초 뒤 시작"
                                              ↑ 같은 자리, 역할 · 방 종류에 따라 바뀜
```

위쪽 = 방 정보 (코드 · 인원 · 나가기 · 지난 판 결과), 가운데 = 사람 (칸 4개), 아래쪽 = 진행 (로그 · 시작). 초대 배너 · 토스트 · 팝업은 그 위에 겹친다. 어느 묶음을 어디에 두는지는 디자인 때 정한다 — **제안**.
