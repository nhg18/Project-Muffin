# 22. 팝업 UI

**최종 수정일**: 2026-11-07 (9절 미정 6건 확정 — PM. 방 만들기 공개 / 비공개 팝업 추가. 같은 날 뒤: 기본 선택 비공개 · 재시도 3회 · 3초 확정, 방 대기 중 끊김 = 즉시 퇴장)
**분류**: UI (공용)

---

> 화면 위에 **겹쳐 뜨는 것** — 팝업 · 토스트 · 배너 — 을 한곳에 모았다. 어느 화면이 무엇을 언제 띄우는지, 공용 판의 모양 · 치수 · 문구 규칙. 각 화면 문서(`10` · `14` · `16` · `17` · `20`)에 흩어진 팝업 항목은 이 문서를 가리키게 바꾼다 (8절). 구분 열이 「제안」 인 것은 승인 전 — 2026-11-07 확정된 것은 날짜를 붙였다.
>
> **시안**: 아티팩트 「찹츄 팝업 UI」 https://claude.ai/artifact/HBxmiZ7z394869acPP7dig — 게시본 ID 는 승인 때 적는다. 시안 1px = 캔버스 2px (`10-ui` 2-1 과 같은 규칙). 룩은 「찹츄 인게임 UI」 와 같다 — 남색 굵은 테두리 · 아래로만 떨어지는 그림자 · 분홍 주 버튼 · Jua + 고운돋움.

## 1. 원칙

| # | 규칙 | 구분 |
| --- | --- | --- |
| 1 | 팝업은 **판정하지 않는다.** 결과를 보여 주고 입력을 받아 요청만 보낸다 (`10-ui` 1절) | 확정 (기존) |
| 2 | **공용 판 다섯 개**(경고 · 확인 · 입력 · 대기 · 토스트)로 거의 다 해결한다. 화면 전용 팝업(친구 · 프로필 · 설정 · 차단 목록 · 플레이어 정보)은 **큰 판** 하나의 규격을 같이 쓴다. 화면마다 비슷한 팝업을 새로 만들지 않는다 (`14` 3절 #3) | 확정 (기존) / 제안 (큰 판) |
| 3 | **모달은 한 번에 하나.** 모달이 열려 있으면 아래 화면 입력은 전부 막힌다. 모달 위에 또 모달이 필요하면 **앞 것을 닫고 연다 (교체)** — 예: 계정 삭제 확인 → 「삭제」 입력. 예외: 전용 팝업(큰 판) 위에는 공용 **대기 · 경고 · 확인** 이 겹칠 수 있다 (친구 팝업에서 「차단」 → 확인) | 제안 (`16` #11 · `17` #4 를 하나로) |
| 4 | **바탕을 눌러도 닫히지 않는다.** 닫는 길은 닫기 버튼 · 「취소」 · 「확인」 · Android 뒤로가기만. 모바일에서 손가락이 바탕에 닿아 실수로 닫히는 일을 막는다. 모든 팝업(공용 · 전용)에 같다 — `16` 7-5 도 이 규칙 | 확정 (2026-11-07, 9절 #1) |
| 5 | **Android 뒤로가기** = 맨 위 팝업의 닫기 버튼과 같다. 닫기가 없는 팝업(대기 · 업데이트 · 점검)은 뒤로가기를 **무시**한다. 팝업이 없으면 그 화면 문서의 뒤로가기 규칙 | 제안 |
| 6 | **열림 · 닫힘 연출 없음** — 즉시 교체 (`17` #10 · `12` 6절) | 확정 (기존) |
| 7 | **씬이 바뀌면 전부 닫힌다** (`10-ui` 8-1) | 확정 (기존) |
| 8 | 토스트는 **쌓인다.** 모달 · 전용 팝업 위에도 뜬다. 3초 · 누르면 즉시 닫힘 | 확정 (기존) |
| 9 | 글자 최소 30 · 누르는 것 최소 122 (`15-screen` 5절) — 모든 버튼 · 닫기 · 토글 · 행 버튼이 이 값 이상 | 확정 (기존 기준) |
| 10 | 팝업 종류는 **제목 띠 색 + 아이콘**으로 구분한다. 경고 = 주황 「!」 · 확인 = 분홍 「?」 · 위험 확인 = 빨강 「!」 · 입력 = 분홍 (아이콘 없음). **경고 팝업의 아이콘은 상황과 무관하게 「!」 하나** — 연결 끊김(⚡) 같은 상황별 아이콘은 두지 않는다 | 제안 (띠 색) / 확정 (경고 아이콘 「!」 하나, 2026-11-07 9절 #6) |

### 1-1. 문구 규칙

| 자리 | 규칙 | 예 |

| 토스트 | 한 줄 · 20자 이내 · 마침표 | 방 코드를 복사했습니다. |
