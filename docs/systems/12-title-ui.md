# 12. 타이틀 화면 UI

**최종 수정일**: 2026-09-25
**분류**: MVP
**출처**: Claude Design 「찹츄 타이틀 화면」을 게시한 아티팩트 `https://claude.ai/artifact/7hXwuwxuZfL7ZXW7VSyoRv` — **기준: 2026-09-24 게시본(`1790251827-b3ed`)에 폰트(학교안심 둥근미소 B/R, 기존 TitleScene 굵기 배분)·배경(게임과 같은 일러스트)을 교체하고 4-3 모바일 확대 · 위치를 반영한 판 (Version 11) → 연결 중 · 연결 실패 상태를 추가한 Version 12 (2026-09-25, 사용자 검증 대기)**
**이전 출처**: 노션 「🎬 타이틀 화면 개발 문서(UI 구현 스펙)」 — 이 문서 기준으로 갱신됨

> 아티팩트가 수정되더라도 **이 문서를 고치기 전까지는 이 문서가 기준이다.** 아티팩트를 갱신했다면 버전 ID와 바뀐 수치를 이 문서에 먼저 반영한다.

---

## 1. 목적

게임의 첫 화면. 플레이어가 닉네임을 입력하고 접속을 요청한다.

## 2. 판정 주체

**타이틀 화면의 모든 판정은 로컬(해당 클라이언트)이다.** 마스터 판정 없음.
닉네임 검증은 입력한 클라이언트가 직접 하고, 서버는 닉네임을 다시 검사하지 않는다.

## 3. 핵심 규칙

| # | 규칙 | 구분 |
| --- | --- | --- |
| 1 | 닉네임 검증을 통과해야만 접속을 요청할 수 있다 | 확정 |
| 2 | 검증 실패 사유는 입력창 아래 에러 문구로만 표시한다 (팝업 사용 안 함) | 확정 |
| 3 | 에러 문구는 닉네임 입력이 바뀌면 즉시 사라진다 | 확정 |
| 4 | 에러 문구가 없을 때도 그 자리(높이)는 유지한다 — 버튼 위치가 움직이지 않는다 | 확정 |
| 5 | 접속 이후 흐름(로비 이동, 닉네임 저장)은 이 문서가 정하지 않는다 → [`01-game-flow.md`](01-game-flow.md) | 확정 |
| 6 | **닉네임 입력창과 접속 버튼은 서버에 연결된 뒤에만 보인다.** 연결 전에는 그 자리에 로딩 표시(회전 링)가 돈다. 연결이 끝나면 자동으로 입력 묶음이 나타난다 | 확정 (2026-09-25) |
| 7 | 연결에 실패하면 로딩 자리에 실패 사유와 **다시 시도** 버튼을 보인다. 입력 묶음은 그대로 숨김 | 확정 (2026-09-25) |
| 8 | 접속 버튼을 누른 시점에 연결이 끊겨 있으면 로비로 가지 않고 연결 실패 상태로 돌아간다 | 확정 (2026-09-25) |

> 2026-09-25 이전 규칙("접속 버튼은 항상 보이고, 누르면 접속이 끝나기를 기다린다")은 폐기. 연결 전에 버튼이 눌리고, 연결 없이 로비로 넘어가는 문제가 있었다.

## 4. 주요 수치

### 4-1. 캔버스

| 항목 | 값 | 구분 |
| --- | --- | --- |
| 기준 해상도 | 1920 × 1080 | 확정 |
| 스케일 방식 | Scale With Screen Size · **Expand** (`15-screen.md` 3절) | 확정 (2026-09-25 변경, 이전 높이 기준 — 폰에서는 결과 동일). 구현은 B1-14 |
| 화면 방향 고정 (가로/세로) | **가로 고정** (`15-screen.md`) | 확정 (2026-09-25) |

> 아티팩트는 `vh`/`vw` 반응형이다. 아래 모든 px 값은 **1080 높이에서 환산한 값**이다.

### 4-2. 닉네임

| 항목 | 값 | 구분 |
| --- | --- | --- |
| 최소 길이 | 2자 | 확정 |
| 최대 길이 | 16자 (입력 자체가 16자에서 막힌다) | 확정 |
| 허용 문자 | 한글 완성형 · 영문 · 숫자 | 확정 |

| 중복 닉네임 허용 | — | **미정** (로그인 시스템 보류) |

### 4-3. 모바일 확대 배율

아티팩트는 1920×1080 모니터 기준이라 폰에서는 글자 · 버튼이 너무 작다
(가로 폰 화면 높이 ≈ 390pt → 캔버스 1 ≈ 0.36pt. 입력 글자 22 ≈ 7.9pt, 버튼 높이 84 ≈ 30pt).
**중앙 묶음만 통째로 확대한다.** 7 · 8 · 9절의 수치는 모두 **확대 전(아티팩트 그대로)** 값이고, 화면에는 아래 배율이 곱해져 보인다.

| 대상 | 배율 | 폰 실제 크기 (390pt 높이 기준) | 구분 |
| --- | --- | --- | --- |
| 로고 · 부제 묶음 | **× 1.3** | 로고 화면 높이의 22%, 부제 ≈ 17pt | 확정 (2026-09-24) |
| 입력 묶음 (입력창 · 접속 버튼 · 에러 문구) | **× 1.7** | 입력 글자 ≈ 13.5pt, 버튼 높이 ≈ 52pt, 입력창 높이 ≈ 45pt, 에러 ≈ 11pt | 확정 (2026-09-24) |
| 로고 묶음 ↔ 입력 묶음 간격 | 56 (확대 후 값) | | 확정 (2026-09-24) |
| 중앙 묶음 전체 위치 | **아래로 198** (1080 기준, `Content` 오프셋) — 로고가 캐릭터 몸통 앞, 입력 묶음이 화면 아래쪽 | | 확정 (2026-09-25, Unity 에서 조정) |
| 버전 표기 · 시스템 버튼 (가장자리) | 배율 없음 | | 현행 유지 · 별도 검토 |

- 기준: 터치 영역 44pt 이상, 글자 11pt 이상 (Apple HIG).
- 아티팩트(Version 11)도 Unity 와 같은 방식으로 그린다: 중앙 묶음 · 가장자리 UI 를 **1920×1080 설계 좌표 그대로** 두고 화면 높이에 맞춰 통째로 스케일(`zoom: 창 높이 / 1080`) — Unity 의 높이 기준 Canvas Scaler 와 같다. 묶음 배율은 `zoom` 1.3 / 1.7, 간격 56, 아래로 198. 1920×1080 · 1920×900 · 1656×930 에서 Unity 좌표와 1~2px 이내 일치.
- (Version 10 은 위치만 `vh` 로 줄고 크기는 고정 px 라, 창 높이가 1080 이 아니면 Unity 와 어긋났다.)

| 입력 | 동작 | 조건 |
| --- | --- | --- |

| 메뉴 버튼(≡) 탭 | **미정** | — |

## 6. 화면 상태

상태는 넷이다. **입력 묶음(닉네임 입력창 · 접속 버튼 · 에러 문구)** 과 **로딩 묶음(링 · 문구 / 실패 문구 · 다시 시도 버튼)** 은 같은 자리를 번갈아 차지한다. 로고 · 부제 · 배경 · 버전 · 시스템 버튼은 모든 상태에서 그대로다.

| 상태 | 보이는 것 | 진입 조건 |
| --- | --- | --- |
| **연결 중** | 로딩 묶음: 회전 링 + "서버에 연결 중…" | 앱 시작(타이틀 씬 진입) 직후. 다시 시도 탭 후 |
| **연결 실패** | 로딩 묶음: 10-5 문구 + 다시 시도 버튼 | 연결 중에 `OnDisconnected` |
| **입력 대기** | 입력 묶음 (저장된 닉네임 복원됨) | `OnConnected` |
| **에러 표시** | 입력 묶음 + 에러 문구 | 입력 대기에서 검증 실패 |

| 현재 | 조건 | 다음 | 화면 변화 |
| --- | --- | --- | --- |
| (씬 진입) | 이미 연결돼 있음 (`IsReady`) | 입력 대기 | 로딩 없이 바로 입력 묶음 |
| (씬 진입) | 아직 연결 안 됨 | 연결 중 | 로딩 묶음 표시. 연결이 끊겨 있으면(`!IsConnected`) 접속을 다시 시작 |
| 연결 중 | `OnConnected` | 입력 대기 | 로딩 묶음 숨김, 입력 묶음 표시 (즉시) |
| 연결 중 | `OnDisconnected(사유)` | 연결 실패 | 링 · 문구 → 10-5 문구 + 다시 시도 버튼 |
| 연결 실패 | 다시 시도 탭 | 연결 중 | 서버 접속 다시 시작 |
| 입력 대기 · 에러 표시 | `OnDisconnected(사유)` | 연결 실패 | 입력 묶음 숨김, 로딩 묶음(실패) 표시 |
| 입력 대기 | 접속 탭 + 검증 실패 | 에러 표시 | 에러 문구 표시 |
| 에러 표시 | 닉네임 입력 변경 | 입력 대기 | 에러 문구 지움 |
| 입력 대기 · 에러 표시 | 접속 탭 + 검증 통과 + `IsReady` | — | 닉네임 저장, 로비(`LobbyScene`)로 이동 |
| 입력 대기 · 에러 표시 | 접속 탭 + 검증 통과 + `!IsReady` | 연결 실패 | 문구 "연결이 끊어졌습니다. 다시 시도해 주세요." |

- 서버 접속은 앱 시작 때 `NetworkManager` 가 시작한다(`01-game-flow.md`). 타이틀은 그 결과를 **표시만** 한다.
- 접속 버튼 글자는 항상 "접속". "접속 중…" 표시와 접속 중 탭 무시 규칙은 폐기 (버튼이 연결된 상태에서만 보이므로).
- 로딩 ↔ 입력 전환 연출(페이드)은 없음 — 즉시 교체. 페이드는 **제안** 단계(디자인 확인 후).

### 7-1. 배치

> **박스 크기는 안쪽 크기다** (아티팩트 CSS 가 `content-box`). 겉 크기 = 안쪽 + 여백 + 테두리:
> 닉네임 입력창 **612 × 74** (여백 22 + 테두리 4 — 입력 묶음 폭 560 보다 양옆으로 26씩 넓다), 접속 버튼 **310 × 84**, 시스템 버튼 **50 × 50**. (구현 세션 실측, 2026-09-24)

| 로고 ↔ 부제 간격 | 6 | | 확정 |

### 10-5. 에러 문구 (접속 실패 사유)

`ConnectionEvents.OnDisconnected` 의 사유(`DisconnectCause`)별 문구. **연결 실패** 상태의 로딩 묶음 안에 표시한다 (2026-09-25 — 이전에는 에러 문구 자리). 자동 재시도는 없다(`09-network.md`) — 다시 시도 버튼으로만.

| 사유 | 문구 |
| --- | --- |
| `ExceptionOnConnect` · `DnsExceptionOnConnect` · `ServerAddressInvalid` (인터넷 없음 포함) | 서버에 연결할 수 없습니다. 인터넷을 확인해 주세요. |
| `ClientTimeout` · `ServerTimeout` (접속 제한 15초 초과 포함) | 연결 시간이 초과되었습니다. 다시 시도해 주세요. |
| `MaxCcuReached` | 접속자가 많습니다. 잠시 후 다시 시도해 주세요. |
| 그 외 | 연결이 끊어졌습니다. 다시 시도해 주세요. |

- Photon 원문 메시지는 보여주지 않는다.
