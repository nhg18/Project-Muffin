## 0. 결론 먼저

디자인 두 사람의 규칙은 세 가지다.

1. **개발보다 한 단계 앞서 넘긴다.** UI 개발이 화면을 만들기 시작하는 날, 그 화면의 시안이 이미 있어야 한다. 마감은 `development-plan.md` 4-2절 D1 ~ D12.
2. **저장소와 Unity 는 만지지 않는다.** 공유 폴더에 올리면 UI 개발이 Unity 에 넣는다.
3. **규격표 없는 납품은 받지 않는다.** 크기 · 9-slice 여백 · 색 hex · 폰트가 적혀 있어야 UI 개발이 반나절 안에 반영한다.

가장 먼저 필요한 것:

| 마감 | 누가 | 무엇 | 왜 먼저 |
| --- | --- | --- | --- |
| **10/2** | 카드 디자인 | 카드 규격 (D2) | UI 개발이 인게임 씬을 다시 만들 때 카드 크기가 필요하다 |
| **10/4** | UI 디자인 | UI 디자인 시스템 (D1) | 모든 화면 시안이 이걸 따른다 |
| 10/7 | UI 디자인 | 인게임 와이어프레임 (D4) | UI 개발이 이걸 배치 수치 문서(`17-game-ui.md`)로 옮긴다 |

## 1. 공통 — 전달 규칙

### 1-1. 공유 폴더

```
/design
  /source          원본 (PSD · Figma 링크 · AI 파일)
  /handoff
    /2026-10-04_design-system/
    /2026-10-11_card-frame/
    /2026-10-11_ingame-hud/
      spec.md        ← 규격표
      *.png          ← 슬라이스
      preview.png    ← 시안 전체 화면 한 장
```

한 번 납품 = `handoff` 아래 폴더 하나. 폴더 이름은 `날짜_무엇`. 고친 버전은 새 폴더로 (덮어쓰지 않는다).

### 1-2. 파일 규칙

| 항목 | 규칙 |
| --- | --- |
| 형식 | PNG, 투명 배경, 32비트 |
| 이름 | 영문 소문자 + 밑줄. `종류_대상_상태.png` — 예: `ui_btn_pill_normal.png`, `card_frame_action.png`, `card_illust_A09.png` |
| 크기 | 화면에 보이는 크기 **그대로** (1920 × 1080 기준 좌표). 카드 일러스트만 예외 (2-1절) |
| 글자 | **이미지에 글자를 굽지 않는다.** 글자는 Unity 가 폰트로 그린다. 시안에는 넣되 슬라이스에서는 뺀다 |
| 폰트 | 학교안심 둥근미소 B / R (이미 프로젝트에 있음). 다른 폰트를 쓰려면 먼저 UI 개발과 상의 |

### 1-3. 화면 규격 (`systems/15-screen.md` 확정 사항)

* **가로 고정, 기준 1920 × 1080.** 모든 시안을 이 크기로 그린다
* 화면 비율이 달라지면 위아래 · 좌우로 **배경만 늘어난다.** 중요한 것은 가운데 1920 × 1080 안에 둔다
* 모서리 · 가장자리 요소(나가기 버튼 등)는 노치를 피해 안쪽으로 밀린다 — 가장자리에서 48 이상 띄워 그린다
* **터치 최소 크기 122 × 122** (폰에서 손가락 크기). 글자는 30 이상
* 색 공간은 Gamma 다 — **시안에서 본 반투명 색이 Unity 에서도 거의 같게 나온다**

### 1-4. 규격표 양식 (`spec.md`)

```
화면: 인게임 HUD — 좌석
시안: preview.png / Figma 링크

| 요소 | 파일 | 크기 (w×h) | 9-slice 여백 (좌 우 위 아래) | 색 | 글자 (폰트 · 크기 · 색) |
| 좌석 배경 | ui_seat_bg.png | 360×160 | 24 24 24 24 | — | — |
| 닉네임 | — | — | — | — | 둥근미소 B · 32 · #FFFDF8 |
| HP 게이지 칸 | ui_gauge_bg.png | 280×24 | 12 12 0 0 | — | — |
| HP 게이지 (위험) | ui_gauge_fill.png | 〃 | 〃 | #FF6E8A | — |

상태: 기본 / 눌림 / 비활성 / 위험 … 상태마다 파일 또는 색을 적는다
움직임: 있으면 한 줄 (예: 내 턴이 되면 테두리가 0.3초 동안 켜진다)
```

## 2. 카드 디자인

### 2-1. 카드 규격 (D2 — 10/2, UI 개발과 합의)

지금 Unity 카드는 **프레임 이미지 + 일러스트 이미지 + 이름 글자 + 효과 글자** 4겹이다. 글자는 Unity 가 그리므로 프레임에 글자를 굽지 않는다.

| 항목 | 제안 | 비고 |
| --- | --- | --- |
| 카드 전체 크기 | **820 × 1222** (약 2 : 3) | 지금 쓰는 임시 프레임과 같다. 바꾸려면 10/2 까지 |
| 일러스트 영역 | 프레임 안 위쪽 — 위치 · 크기를 규격표에 | 일러스트 원본은 이 영역의 2배로 그려 축소한다 |
| 이름 칸 | 한 줄, 최대 8글자 | 기획 R 이 카드 이름을 이 길이 안에서 짓는다 |
| 효과 문구 칸 | 최대 3줄 · 45글자 안팎 | 기획 R 의 카드 시트 "효과 문구" 열이 이 칸에 들어간다 |
| 종류 표시 | 행동 / 카운터 / 함정 — 색 + 아이콘 | 함정 뒷면(설치된 함정)도 구분 가능해야 한다 |

### 2-3. 일러스트 59장 범위 — 10/25 에 정한다 (제안)

1명이 10/12 ~ 1/10 에 59장이면 **주당 약 5장**이다. MVP 6장의 실제 속도를 보고 둘 중 하나를 고른다.

| 선택지 | 내용 | 맞는 경우 |
| --- | --- | --- |
| 가) 59장 모두 고유 | 카드마다 다른 그림 | 1장에 하루 안쪽으로 그릴 수 있을 때 |
| 나) 계열 공용 + 핵심 고유 | 효과 계열(공격 · 회복 · 드로우 · 손패 · 함정 · 무효화 …)마다 공용 그림 약 12장 + 자주 나오는 카드 약 20장은 고유 | 1장에 이틀 이상 걸릴 때 |

어느 쪽이든 **MVP(12/2) 는 공용 그림을 허용**하고, 고유 그림은 출시(1/25)까지 채운다.

## 3. UI 디자인

### 3-1. UI 디자인 시스템 (D1 — 10/4)

타이틀 화면은 이미 디자인이 있다 (`systems/12-title-ui.md`, 기준 시안 아티팩트). **그 스타일을 모든 화면으로 넓히는 규칙집**을 만든다.

| 항목 | 정할 것 | 출발점 |
| --- | --- | --- |
| 색 | 기본 · 강조 · 성공 · 위험 · 비활성 · 글자 · 외곽선 — hex 로 | 타이틀: 글자 `#FFFDF8` · 외곽선 `#3A2246` · 보라 버튼 `#B18AE0` · 에러 `#FF6E8A` |
| 글자 크기 단계 | 제목 · 소제목 · 본문 · 작은 글자 (1080 기준, 최소 30) | 타이틀 12-title-ui 8절 |
| 버튼 | 큰 버튼 · 작은 버튼 · 아이콘 버튼 — 기본 / 눌림 / 비활성 | 이미 있는 `PillButton` · `IconButton` 프리팹 |
| 박스 · 패널 | 둥근 사각, 반투명 정도, 테두리 | 타이틀 입력 박스 |
| 아이콘 | 크기 규칙, 선 굵기 | — |
| 그림자 · 외곽선 | 글자 · 버튼 그림자 규칙 | 타이틀 로고 · 버튼 |

### 3-3. 와이어프레임과 배치 문서의 관계

1. UI 디자인이 와이어프레임을 그린다 (위치 · 크기 · 겹침 순서)
2. UI 개발이 그걸 숫자로 옮겨 `systems/17-game-ui.md` 를 쓴다 (12 · 14 · 16 과 같은 형식)
3. 그 뒤 시안은 **17 번 문서의 크기 · 위치를 지킨다.** 바꾸려면 문서를 먼저 고친다

### 3-4. 디자인 검수 (M5)

UI 개발이 디자인을 넣으면 Unity 화면을 캡처해 공유 폴더에 올린다. UI 디자인이 시안과 나란히 놓고 다른 곳을 표시한다 (색 · 위치 · 크기 · 글자). 타이틀 화면에서 이 방식으로 1px 단위까지 맞췄다.

## 5. 하지 않는 것

* 저장소 · Unity 파일 직접 수정 — 공유 폴더로만 전달한다
* 이미지에 글자 굽기 — 글자는 Unity 가 폰트로 그린다
* 확정된 배치(14 · 16 · 17 문서)를 말없이 바꾸기
* 기획이 정하지 않은 카드 이름 · 문구를 임시로 지어 확정처럼 넣기 — 임시면 파일 이름에 `_temp` 를 붙인다
